## Observed Java kernel state

`native-kernel-observation.json` observed the real Java source child with
NoNewPrivs 1, Seccomp 2 and one seccomp filter, while the direct native worker
itself had those flags unset. The live MCP cancellation child separately had the
same active flags; its PID/start identity is retained in
`live-cancel-java-kernel-flags.json` and the cancellation record.

These observations prove the filter and NoNewPrivs were active in those
children. The network-denying syscall set is established by the fixed runtime
implementation and successful filter-installation path. The harness did not
decode installed BPF rules or send a network connection challenge.

A 16 MiB per-file limit applies to scratch. Aggregate scratch usage is sampled
every 250 ms against 64 MiB / 1,024-entry budgets; it is not a hard filesystem
quota. Owner interruption can leave logged private scratch, as this cancellation
case did. The fixed bridge emits one javac deprecation warning for the supported
Ghidra 12.2 `Loaded.getDomainObject()` method; it does not affect this pinned
import result and is preserved in the native report.

## Recipe

Use an independently verified official Ghidra 12.2 installation that is
non-writable to the actual JVM identity, a separately pinned JDK 25, and existing
localhost SSH/user-systemd support. Choose a new workspace:

```sh
python3 tests/rea_ghidra_external.py   --runtime /absolute/path/to/the/exact/binary   --java-home /absolute/path/to/jdk-25.0.5+8   --ghidra-home /absolute/path/to/ghidra_12.2_PUBLIC   --workspace /absolute/new/private/qualification-directory   --execution-mode operator --allow-local-ssh
```

The harness refuses an existing workspace. Engine distributions, runtime
binaries, state databases and credentials are excluded from this evidence
directory. This is a bounded import adapter; it does not claim full upstream REA
or Ghidra capability parity.
