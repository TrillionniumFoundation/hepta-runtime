# Integrated current source and the original historical qualification domain

The integrated runtime source keeps the original historical58 source profile and
its complete 195-component native domain. A separate, fixed source transition
admits the newer physical source before producing that historical output.

## Why this transition is needed

Integration base `cb5fa1ee8acbf3e68c74c062fda869812112c433` combines the normal
parents for public native work, original metadata restoration and lossless
evidence transport. It has 235 physical HIA source files under `native/`.
The migration declaration contains 196 components: its only change from the
fixed historical declaration is the `native_read_bootstrap.hepta` row. Five
current HIA files also remain after the older graph's exclusions. They must be
declared explicitly in the transition before the historical output can recover
its complete original 195-file roster.

The transport work changes two workflow files whose complete predecessor bytes
are already fixed by the retained v8 profile. On exact head
`71d113f2402f8cc518188eaa00c197b7cc3c8966`, hosted job `140920531618`
correctly refused `hia-runtime-native.yml` during source materialization. Job
`140920531193` passed 11 original source tests and failed the materialization
test for the same reason. Neither run reached the native upload. Their complete
logs are retained with this qualification evidence.

## Capture and output verification

Every input is read from the explicit physical root. Regular-file and physical
parent checks reject substituted symbolic links. The snapshot captures device,
inode, mode, link count, owner, group, size, mtime and ctime and repeats the
complete bytes and physical identities at terminal admission. The native roster
and parent identities are also repeated. A full independent root containing the
same reader bytes is supported; a different or missing reader copy is rejected.

The projected historical bytes are kept separate from captured current bytes.
Supplying a predecessor as a physical current file is rejected. Only the new
output receives the three restored files and five additional exclusions.
The retained original readers still verify the 53 runtime paths, 84 workdir
paths, their 131-path union, the 71 production metadata paths, the complete
199-path reference/metadata union and the exact 195 native source roster.
Rewriting an output receipt cannot admit altered fixed source bytes.

The source-profile labels for historical58 and current126 are retained v8
identities. This transition does not claim that a current runtime executable,
the whole SDK, or the latest default image set has been qualified by these
source-only checks.

## Original and added controls

All 12 original public source test methods have identical ASTs. Only their
class setup and source-fixture helpers now prepare the explicitly admitted old
195-row inventory. The eight-test metadata file is byte-for-byte unchanged.
The fixed original profiles, original assertions, case counts and process
timeouts are retained.

Sixteen added methods cover complete independent roots, all three full inverses,
fixed authority mutations, changed/missing transport and HIA sources, unexpected
roster entries and execution modes, physical-input/projection confusion,
different reader copies, file and directory symlinks, terminal drift in every
changed domain, same-byte inode replacement, late native additions, complete
materialized output, forged receipts, all five historical exclusions and
optimized Python parents.

On the final candidate, all original 20 and added 16 methods pass with zero
skips. The exact source check also passes. Full logs, source identities,
per-method AST comparisons and durations are in `verification.json`.

The native workflow retains all 49 existing step objects and adds one separate
16-control step. The historical source workflow retains both prior step objects
and adds the same control suite. Every existing job dependency, strategy and
time budget is unchanged, including the 15-minute native admission/upload
budget and all original comparison groups.
