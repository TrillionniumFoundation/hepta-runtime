## Run against PR #34 from a trusted Hepta Runtime checkout

On your Linux/macOS development host with Git, Python 3.9+ and Rust 1.95.0 + rustfmt + clippy:

```bash
cd /path/to/hepta-runtime
git fetch origin 'refs/pull/34/head:refs/qualify/34-head'
git fetch origin 'refs/pull/34/merge:refs/qualify/34-merge'
SOURCE_SHA=$(git rev-parse refs/qualify/34-head)
MERGE_SHA=$(git rev-parse refs/qualify/34-merge)
python3 /path/to/unzipped/scripts/local_qualification.py \
  --repo "$PWD" \
  --source-sha "$SOURCE_SHA" \
  --merge-sha "$MERGE_SHA" \
  --output "$HOME/hepta-runtime-qualification/34"
```
