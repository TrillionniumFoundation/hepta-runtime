# Hepta Runtime executable PATH source-qualification guard

This is a self-contained offline test of `scripts/qualification_path_fence.py`, the Python guard added in TrillionniumFoundation/hepta-runtime PR #52. It does **not** contain the full private Hepta Runtime repository or Rust source, and does not prove full project compilation or runtime deployment readiness.

## Offline test

```bash
python3 -m unittest discover -s scripts -p test_qualification_path_fence.py -v
```

As tested on the analysis container: 6 tests passed. The harness also reproduced that a fake `git` under the unreviewed repository directory executes when this directory is prepended to PATH, then verified that the guard rejects that PATH. Full exact-source and GitHub PR synthetic-merge tests require an environment with the repository and Rust 1.95.0.

GitHub code review: https://github.com/TrillionniumFoundation/hepta-runtime/pull/52
