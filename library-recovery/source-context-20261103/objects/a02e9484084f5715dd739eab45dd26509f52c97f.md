## 在已正确挂载的可信本机工作树中运行

脚本只能在**真实拥有目标源码及工具链的主机**上执行，不能在当前容器替代物理测试。构建或运行 Rust 测试会执行仓库受信任的源码/脚本。推荐将输出路径放在代码工作树之外。

```bash
python3 hepta_local_gate.py \
  --repo /path/to/hepta-runtime \
  --kind hepta-runtime \
  --expected-head a26c01a16833b1cf80a9d468ae101af72f30fbbe \
  --out /tmp/hepta-runtime-gate.json

python3 hepta_local_gate.py \
  --repo /path/to/hepta-private-ci \
  --kind hepta-private-ci \
  --expected-head f8c9419df6ddeb36ff8b522a50219981fb8d9345 \
  --out /tmp/hepta-main-gate.json
```

脚本返回 `0` 表示**且仅表示**该源码工作树的 5 项本地 Rust 原生命令通过；返回 `1` 代表运行了但有测试失败，返回 `2` 代表源身份、环境、输入或工具链不满足。`production_qualified` 始终为 `false`；不得用本地 Cargo 的 PASS 替代物理目标、独立授权、学习有效性、样本外验证、资源规模或恢复验收。
