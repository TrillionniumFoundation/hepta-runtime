### P0 source defect A: mismatched remote job observations

Before this PR, remote STATUS/READ/CANCEL helpers checked `job_id` but not the controller's immutable full request digest and effective unit. A foreign/restored request file sharing the same job ID might produce misleading status/logs or allow cancellation of a different remote operation.

**Candidate fix:** controller sends `request_digest` and `unit` on status/wait/read/cancel; the remote helpers reject missing/mismatched ID, directory, unit, full SHA-256 digest before observing a terminal state, returning logs or signalling a process. Legacy rows without full digest are locally listable only, not remote effect authority. Regression coverage includes three negative helpers and positive exact-match status/log reads.

### P0 source defect B: ambiguous stored controller state relaunch

Before this PR, duplicate `process_start` for persisted `pending` or `launch_failed` rows attempted `launch_record` again. If remote evidence had been lost, this might re-execute an already dispatched effect.

**Candidate fix:** duplicates are observation-only for previously acknowledged `launched` rows. `pending`, `launch_failed`, and unknown states fail closed as indeterminate; no remote relaunch is attempted. A Rust regression tests these dispositions. Operator reconciliation is required for uncertain original effects.

**Security limits:** These are *source-level* safeguards, not cryptographic physical-host attestation, tamper-proof remote records, independently signed Final-use grants or verified exactly-once execution.
