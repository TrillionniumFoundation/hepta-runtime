# Hepta 本机阻断项验收工具（证据采集版）

本工具用于已有的 **hepta-private-ci** 与 **hepta-runtime** 工作树。不会克隆、拉取、切换分支、修改源文件、自动合并、部署、授权 Final-use 或将测试成功升级为生产 GO。

## 在你自己的 Linux/macOS 开发主机上运行

确保已安装 Git、Rust 1.95.0 + rustfmt/clippy、just 和项目所需的 cargo-nextest/构建依赖。`--bazel` 需要额外安装 Bazel。下面路径仅为示例，请替换为你已有代码目录：

```bash
python3 hepta_local_blocker_runner.py \
  --hepta "$HOME/src/hepta-private-ci" \
  --runtime "$HOME/src/hepta-runtime" \
  --scope full --bazel \
  --output "$HOME/hepta-qualification-20261023"
```

如需先仅查看当前工作树身份与工具链是否具备：

```bash
python3 hepta_local_blocker_runner.py \
  --hepta "$HOME/src/hepta-private-ci" \
  --runtime "$HOME/src/hepta-runtime" \
  --check-only \
  --output "$HOME/hepta-preflight-20261023"
```

如果必须验证指定代码，使用 `--expect-hepta-sha <40字符SHA>` / `--expect-runtime-sha <40字符SHA>`，任何不匹配直接判为 BLOCKED。

结果存放在指定目录的 `qualification.json` 及每项命令的原始日志中。退出码 `0` 仅表示执行的**本机测试检查**全通过；`2` 表示环境、源码、工具链或测试不满足本机验收。即使本机检查全绿，也不代表 PR HEAD 和 GitHub 合并候选都通过、真实 SSH 物理主机已经验证、独立签名 Final-use 授权通过或具备生产部署资格。

静态确认 Python 测试：

```bash
python3 -m unittest -v test_hepta_local_blocker_runner
```

### 安全约束

首次检查会拒绝来源树内、相对路径或不存在的 `PATH` 命令搜索目录；拒绝缺失/脏工作树、HEAD 不匹配和工具链版本不符；每个命令有超时和独立日志摘要。**不会上传报告**（报告可能包含项目路径与测试输出）。本脚本本身没有办法观察真实云/主机操作、验证密钥授权或替代隔离、持续运行和故障注入。所有失去证据的阶段必须保持 DENY_ALL / HOLD_NO_GO。
