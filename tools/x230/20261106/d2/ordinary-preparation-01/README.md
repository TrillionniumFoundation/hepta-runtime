# D2 ordinary feature-off supplement

The standalone supplement uses the same already formatted D2 222-file source map. It preserves the three qualified all-features release executables before reusing the independent build target. It then runs the original clippy, test-build, isolated-tests, audit-isolated-tests and release stages. It does not rerun format, fmt-check or harness-tests. The generic qualifier is the exact reviewed 7,320-byte five-stage producer from D1.

The three `--all-features` arguments are omitted. No `--no-default-features` argument is added. D1 and D2 Cargo.toml bytes must match, and their sole package feature is the empty `phase-cost-diagnostics` feature. Dependency defaults and release profiles are unchanged. Cargo artifact records must show no selected package features. Actual ordinary counts remain dynamic and need not equal diagnostic-feature counts.

The first namespace is `ordinary-tools-01`, `ordinary-01`, `ordinary-plan-01.json`, `ordinary-verification-input-01.json` and `ordinary-postflight-01.json`. Native read originals use `ordinary-native-read-01-000.json` and contiguous numbered pages. There is no historical D1 preflight failure chain in this fresh D2 attempt.

The immutable `ordinary-prerequisites-01.json` requires actual Q and exact CI closure. The launcher reads the canonical D2 module and performs its full fresh proof before same-PID exec of the five-stage producer. It retains the existing three-GiB free-space guard. The read-only verifier keeps its four-argument API and emits `hepta-d2-ordinary-supplement-validation/v1` and `hepta-d2-ordinary-supplement-postflight/v1`.

All source_input/tested/after maps must remain exactly the qualified D2 map, and all six release files are read and bound. The original isolated auditor's complete recorded before/after test ELF identities are retained; the postflight does not add another full-body read of the approximately 500-MiB test ELFs or introduce a false 128-MiB test-size gate. Native terminal/pages, five full stage streams, complete inventory and original audit inputs remain required. No auditor is rerun by postflight.

The launcher is SPEC=None, the launch/result seal requests are unsealed, and no ordinary compiler or verifier has been run during this preparation. Actual successful ordinary closure must later be a mandatory C1 prerequisite. It is not a performance result.
