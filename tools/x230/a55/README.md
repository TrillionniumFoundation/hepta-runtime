# A55 frozen qualification and diagnostic tooling

These are the exact reviewed and executed source files and immutable input
bindings for the A55 intermediate checkpoint. The qualification source bundle
is the original pre-format execution input; the eight published Rust bodies
are the actual qualified post-format bodies. Their identities are separate.

The guarded entry, core, source bundle, original protocol, invocation and
preparation manifests preserve their original X230 paths and candidate pins.
The diagnostic wrapper called the large-workload reference implementation for
one fixed diagnostic controller; the full four-controller benchmark was not
executed for A55. The reference protocol is retained to prove the unchanged
deadlines and workload policy, not to claim that benchmark passed.

The pure phase module retains its historical `pending` filename and inert
standalone main. Its audited function was invoked by the completed enclosing
original-byte, stderr, call and cohort auditor. Its own standalone main is not
an evidence audit or a runtime command.

These files retain the historical workspace and remote path contracts. They
are publication evidence, not commands to rerun against a new checkout without
fresh candidate identity, fresh output paths and a reviewed invocation. See the
[actual results and retained bytes](../../../docs/experiments/x230/a55/README.md).
