## Source and native coverage

`snapshot_inputs_02.py` checks all original 401 byte lengths and SHA256 hashes, adds only the fixed late evidence trees, and records original descriptor identities. It does not treat incomplete private07 transfer as publication completion. `check_native_custody_01.py` reuses the earlier reviewed JSON walker and independently reconstructs native streams from the original hex/text/cursor/EOF records. No source or archive code is executed by the packager or tar verifier. No process, SSH, qualification, CI, benchmark, or host RPC is rerun.

## Archive format and verification

`build_custody_bundle_01.py` requires a fresh local output directory and an explicit SHA256 of the actual completed private07 QA file. It keeps every selected original file byte for byte. The archive contains one manifest, sorted payload members, and the pinned packaging source and coverage metadata. Every member is a regular USTAR file with fixed mode, UID, GID, timestamp, and owner names; compression is XZ preset 6 with SHA256 integrity checking. Identical frozen inputs produce identical archive bytes.

`verify_custody_bundle_01.py --bundle ABSOLUTE_BUNDLE --compare-originals --out FRESH_REPORT` validates the complete single XZ stream, exact compressed end, USTAR member set and metadata, every payload SHA256, zero tar padding, full original401 inclusion, and the preserved unknown outcome. The local `--compare-originals` mode also compares every member to its original file bytes and descriptor identity. It never extracts or executes an archive member. Without that flag it verifies the delivered archive independently but does not claim access to the original workspace.
