# Real ArchiveStamp and cache methods

This profile contains the frozen `archive_stamp` owner and a persistent cache caller for `cache_hot_owned`, `hot_snapshot_cached`, and `update_cached_completion`. Both static executables call the real held-descriptor metadata and shared Namespace owners. Private inspection exposes the complete cached Record vector to the qualification harness.

Trusted startup fixtures lend actual directory descriptors. The image bytes, syscall prefixes, call offsets, and compiler pin remain frozen. The legacy source is an exact IR import ancestor; including it does not qualify the complete legacy Archive owner.

## Mandatory evidence

The build compiles five HIA images and invokes two native HIA packers. Admission checks both entire ELF files, every embedded image, retained compiler buffers, actual compiler stdout, packer frames and stdout, and fixed source maps. Reusing a verified bootstrap is recorded separately and is not a fresh full cold qualification.

## Portable entry points

`scripts/build_audit_stamp_graphs.py --hepta PATH --build-root PATH` constructs both graphs. `scripts/hia_native_stamp_qualification.py` supplies `build_stamp`, `build_evidence`, `commands`, `native_evidence`, and `source_pins`.

`tests/hia_native/run_stamp_native.py --build PATH --output PATH` runs all six native processes. `tests/hia_native/compare_stamp_original.py` runs `stamp` or `cache_stamp` and requires the external SHA of this invocation's complete native evidence. `scripts/check_stamp_evidence.py` operates on quiescent outputs.

Every native suite and original recipe retains its 180-second outer budget and three-second cleanup budget. Scenario responses and child exits retain their original 15-second bounds. Internal reference children inherit their owned outer group. No additional parent-death cleanup guarantee is inferred.
