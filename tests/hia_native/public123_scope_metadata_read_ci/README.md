# Pure retained metadata diagnosis

Reads the exact700-file uploaded Scope WAIT capture, all original/native process records, full wire/files/state, complete host traces and every Scope/context buffer. It retains the original FAIL and reports exact differing fields plus full raw metadata. It executes no native or original application and does not change a reader's acceptance rule. Full qualification remains false.

This successor also reads the complete retained callable atomic-write row and closed temporary-FD state for the already captured numeric/string-ID scenario. It does not change comparison acceptance or execute any application. It reports the retained bytes before interpreting inode lifetime.
