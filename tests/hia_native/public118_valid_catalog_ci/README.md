# New valid configured catalog domain

This package compares 6 legacy and 5 modern `tools/list` inputs using a newly frozen valid administrator configuration with one inert host. Both original and native receive the same configuration JSON. The native uses its actual `--runtime-config FILE` startup. The existing original fixture retains its exact serde constructor and `install_for_reference` seam; its omitted CLI startup effects are not claimed as compared. No runtime image or Rust binary is rebuilt.

The old no-host fixture and both failed native comparisons remain retained with complete archives and readers. They are not relabelled as passing, and the old 835 original observations are not replayed. The two new configuration inputs have independent source and input hashes derived in pure CI. The 824 other original operation observations and all previously passing raw/process domains remain on their existing evidence.

The source admission binds the exact recording-driver preimage, only the native CLI argument forwarding, the new configuration input definition, and the actual compiled original Rust source. The complete reader compares every initialization, request, reply, session/cache/lock observation, file snapshot, process stream, source file, and termination receipt. Eight physical controls include removing the actual configuration arguments consistently from all process receipts; both sides must reject that corruption.

Each original and native lane keeps the existing 180 second outer and 60 second exchange limits. Jobs retain the 15 minute limit. The actual native state directory remains under the owned capture and is archived after shutdown. These tests do not qualify public WAIT, cancellation, remote access, the entire SDK, or the entire runtime.
