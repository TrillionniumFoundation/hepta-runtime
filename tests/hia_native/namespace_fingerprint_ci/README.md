target namespace_version.rs. It does not qualify the inotify Watcher,
ContentWatchSet, namespace_version's global selection, archive_store,
HOT_CACHE, begin/finish callers or any public handler.

The native callable owns the HIA continuation and invokes six actual libc
functions. There is no Python/Rust filesystem dispatcher in this callable.
The observer only copies complete borrowed bytes; the same complete domain
runs with observation absent.

There are 72 cases, 156 operations and ten fixed real-kernel groups. One owned
traced process group, bounded at 60 seconds, runs the observed native callable,
observer-free native callable and fresh unchanged Rust function against each
same physical tree. Inodes, raw names, directory-entry order, complete file
contents/modes and all snapshots are preserved. No sorting or expected reply
is fed to either implementation. The seven error groups use actual seccomp
errno refusals; they never synthesize a native effect acknowledgement.

Both native variants capture every outer input/output/workspace/table before
and after, and the observed variant captures every HIA and libc borrowed
record before and after. The Rust side preserves full stdout/stderr, error
display/debug/chain and all fixture commands. Every child is reaped before
evidence sealing. Complete filesystem snapshots precede exact owned retirement.

HIA packer output and the complete flat image are retained. Cargo uses the
exact target versions, including sha2 0.11.0, and a separate locked reference.
