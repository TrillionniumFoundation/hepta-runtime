# Rebuilt Batch private core

This package is a new, reproducible version of the Local Batch body and its
typed parameter carrier. It does not reuse qualification claims from the lost
private91 source tree. The source profile records every admitted input. The
generated HIA bodies, retained owners, assembler boundary, authors and original
source extraction are all included.

## What the recipe actually checks

`run_recipe.py --phase all` runs only on the CI host. It checks an independent
checkout of runtime target `d3d75c30719db966b004756f610007a7c723729e`, builds two
fresh original executables with Rust 1.95.0, and constrains every dependency to
the target's exact Cargo lock. The fixture uses rmcp 3.9.0 and Tokio 1.53.3.
Fifteen original body fragments and two parameter fragments remain byte for
byte equal to the selected target source. The actual registry archives and
all source member identities are retained, together with complete compiler
process streams and both fresh executable bytes.

The native build compiles five parameter/gateway/caller modules, sixteen body
and adapter modules, and one fixture packer. The private body uses fourteen
actual HIA owners. The callable is assembled and linked without external
relocations; the final executable is packed by the actual HIA packer. The
reader checks every complete compile output, untouched tail, compiler stdout,
receipt, manifest, source, image, bootstrap identity and packer buffer.

The typed domain retains 417 typed cases, eight private top-level controls and
22 actual SDK extractor cases. Native qualification performs 3,143 calls,
including 115 frame/capacity/recovery controls, and records 720,021,713 complete
input, workspace and output bytes. The 417 carrier rows are compared against
the unchanged typed owner and the newly built current original. SDK controls
use the actual current extractor rather than assuming its error formatting.

The filesystem domain retains all 926 existing cases in one native session
and one original session, using the same absolute fixture path and permission
identity. Each side keeps the original 180-second process bound and 60-second
individual exchange bound. This includes all fifty-operation requests, large
5 MiB content/file cases, validation order, original line endings, conflict
resolution, modes, invalid UTF-8, missing paths, symlinks and temporary-file
errors. The reader compares complete request/response streams and every
captured file byte, mode and link identity. It also strictly decodes all 5,556
native before/after cache, history and lock arena frames and compares them to
the actual original states. Original hint observations remain explicit.

After those comparisons, the reader verifies a complete final filesystem
archive before retiring only the exact owned live fixture directory. The
evidence control suite uses real independent copies of precisely the admitted
source/evidence files. It requires two relocated admissions and eighteen
data-only refusals, including rehashed compiler buffers, native state tails,
filesystem observations, original executable bytes and complete replay data.

`run_recipe.py --phase verify --output PATH` launches no owner or compiler
process and writes no file. It reopens every required source, process stream,
full buffer, registry archive, semantic record and control mutation. The
artifact exporter includes all these files and records nonregular failure
fixture nodes without following symlinks. Only explicitly identified Cargo
build intermediates are omitted; both recorded fresh executables are kept.

## Build and verification

The workflow in `workflow.yml` is installed externally as
`.github/workflows/hia-batch-private.yml`; the same file remains in the pinned
source closure. Its source package is installed at
`tests/hia_native/batch_public_ci/source`.

```sh
python3 -B run_recipe.py --phase all \
  --hepta /absolute/fixed-Hepta-checkout \
  --target /absolute/independent-d3d75-checkout \
  --rust-bin /absolute/rust-1.95.0/bin \
  --output /absolute/new-evidence-directory
python3 -B run_recipe.py --phase verify --output /absolute/new-evidence-directory
```

Local development may build HIA with a copied, verified B1/B2/B3 bootstrap.
Local Rust compilation is not an admitted path. The recipe refuses a local
fresh original build. All success claims depend on the actual new CI result;
the package itself does not assert that an unexecuted comparison passed.

## Composition boundary

`ABI.md` defines the parameter carrier, body adapter and callable ownership.
The gateway and caller are compiled here, but this recipe does not claim their
public routing, admission, request-scope or fence integration is qualified.
The native file session drives the body directly with admitted typed plans.
The body still uses its actual lock, history, read, plan, apply, atomic-write,
render and cache owners.

The following remain false in every aggregate receipt: public Batch routing,
gateway/caller qualification, full asynchronous cancellation, Remote/SFTP
execution and complete runtime replacement. The fixed ordinary domain does
not certify arbitrary concurrency, process shutdown, or wide request-scope
input windows. A later public composition must bind these exact sources and
repeat its own target wrapper, SDK, scope, result and session comparisons.
