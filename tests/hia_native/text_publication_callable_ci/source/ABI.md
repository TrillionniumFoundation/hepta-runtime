# Private synchronous publication callable ABI

`text_publication_create(callback, callback_context)` returns an owned 4 KiB context or a negative native allocation error. Its immutable three HIA entries are fixed by the HIA packer. A nonzero callback is a trusted observation-only capability. It receives (callback_context, context, event, borrowed_span, length), must return zero, and may not modify the context or supplied span.

`text_publication_invoke(context, input, length)` accepts only a complete HTPBQ001 start frame. The graph supplies the already resolved absolute path; this frame is not a policy or identity credential. A return of 64 publishes the full HTPBS001 frame at context+104, with complete extent at +168 and capacity at +112. The graph must retain that borrow until `text_publication_release(context)` succeeds. A second invoke or destroy while the final result is borrowed returns 0xfffffffd without changing any context or arena byte. All HIA capacity-growth requests preserve the complete workspace prefix and zero extend it; syscall replies are held until consumed, so growth never repeats an OS effect.

State at +56 is 0 idle, 1 active, 2 borrowed final, 3 fatal private failure. +184 is the exact live FD count; +256 contains eight actual owned FD slots (empty -1). The body image owns FD opening/closing order. A normal final result requires zero live descriptors. Explicit destruction rejects active/borrowed state; a fatal private failure may close remaining owned FDs but never becomes a successful body result. Production cancellation/future drop is not implemented by this synchronous capability.

Pointer/capacity pairs at +64/+72 (complete original input), +88/+96 (body workspace), +104/+112 (body output), +120/+128 (callback reply) are context-owned and followed by inaccessible guard pages. +136 and +144 point to fixed 4 KiB child output/work arenas. All allocations are independent. +192 is the monotonically increasing invocation generation. +200/+208 is the currently borrowed HIA input, which may be the owned original input or the owned callback reply. +216/+224/+232/+240 track the actual continuation sequence, operation, raw return, and produced reply extent. +248 counts actual body calls within this invocation.

The private test executable alone understands HTPCFQ01 (64-byte header: command, context 0/1, payload length, four zero words), preceded by its u64 complete length. Commands 1 invoke / 2 release / 3 destroy / 4 full context / 5 full work / 6 full output / 7 full input / 8 create never become public JSON selectors. HTPCFR01 is a 64-byte response header: return code, payload extent, state, generation, live FD count, output capacity, workspace capacity; its full payload immediately follows. EOF releases an already delivered final result and destroys both fixture contexts.

FD3 is fixture-owned and open before startup. HTPCJR01 journal records have a 128-byte header containing event, generation, body-call index, payload extent, state, last HIA code, final extent, work/output capacities, live FD count, current input length, sequence, operation, raw callback return and callback extent. Every declared payload is written in full. Events 1/2 bind complete HIA input/output; 3/4 capture complete before/after workspace growth; 5/6/7 bind actual SHA input/output/work; 8/9 bind raw OS action and callback; 18/19 bind actual HIA errno rendering. The fixture and callable have no public production route.
