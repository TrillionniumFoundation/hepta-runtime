## Gateway

The borrowed three-buffer entry preserves all 35 non-parameter gateway functions,
after exact private-magic relocation. HTPWGQ02 carries the previously resolved
experimental metadata and HTPWGQ03 carries complete raw metadata through the
actual existing client_context owner. Their 48-byte framing is identical to the
retained Text gateway. Typed input is the actual canonical Map produced by the
SDK Value owner. The child typed request uses HTPPRQ01; its exact
24-byte typed frame and complete 128-byte result are separately qualified.

The sequence remains typed projection, actual fence admission, actual session
context and current workdir, actual configuration/path policy, caller, owned
complete result, then actual fence release. Business errors and typed errors
retain their distinct HRCFGM01 kinds. No context or identity is selected in Python.

## Caller

A private installation is exactly 32 bytes: HTPCLI01, context slot, previous lease
identity, and zero. The retained installation entry requires a fresh state. It
returns HTPCLR01 and preserves its existing trusted-session ownership rules.
A request has a 48-byte HTPCLQ01 header: operation 1, full typed-result extent at
16, workdir byte length at 24, and two zero reserved words. The complete HTPPRR01
frame and then workdir bytes follow. No public JSON accepts the installation frame.

The existing Scope state machine, generation/continuation checks, lease handling,
growth admission, child acknowledgment, delivery retry, hint assembly, and close
remain byte-equivalent at the HIA AST level after the documented magic relocation.
Only the six typed/business routing functions are replaced; new business helpers
are appended. Phase 2 uses a private substate at workspace offset 424; phase 3
uses offset 440, with cache-key length at 448. These offsets belong to the caller
workspace, not the engine header.

After actual Scope open, the caller validates the expected digest, then the 64 KiB
UTF-8 content byte limit. It invokes actual configuration presence, resolves the
path through the existing path owner, rejects remote publication with the exact
original error, and invokes actual local path policy. The synchronous callable
owns OS effects and complete body bytes. The caller owns the completed body result
before resolving the actual lock key and issuing HVCACH01 operation 3 through
HRSCQ001 operation 9 on the same active Scope. Scope generation, continuation,
context slot, lease, and the complete cache reply are verified. On success it
appends actual hints and closes Scope; body or preflight failure closes without
forget. The original text publisher does not add file history.

## Return and growth

Caller CALL is 0xfffffff0 with a complete 112-byte HTPCCA01 action at workspace 256.
Gateway uses HTPWGA01. The original sequence, phase, borrowed input/output and
delivery-only acknowledgment rules remain unchanged. HGRWS002 returns
0xffffffd0 and names the complete required capacity. Retrying an output delivery
does not reexecute publication. The callable's return 64 is the fixed header
extent; the controller consumes all 64 plus declared payload bytes before its
borrow is released. HRCFGM01 is 32 plus its full declared result.

All combined runtime, actual cache/session/fence comparisons, public route,
async task lifecycle, and installed-production flags remain false in this build
package. Only future actual combined runs can change those qualifications.
