# Exact original extract raw stdio capture

This source freezes six new real-stdio lanes: one ordinary exchange chain in each protocol era, 48 protocol-shape processes per era, and five EOF processes per era. The original target binary was compiled and qualified in run 43996932889. This gate only copies and reopens that complete immutable build; it does not compile Rust or HIA and does not replay the already retained 835 original private-fixture operations.

Every complete stdout line, any final non-LF tail, complete stderr, actual exit code, attempted and accepted stdin, and filesystem bytes and metadata are retained. No output count, error wire, or EOF outcome is authored. Known request IDs only control when the collector may move to its next source-bound input.

For protocol trials, the unchanged trial bytes and unchanged recovery request are sent as one consecutive input batch. This decision is frozen before execution. All potentially typed-valid extract trials use an invalid from_path array, so this scheduling introduces no second valid edit. All actual output lines through the recovery ID, barrier ID, and final EOF remain evidence; unexpected cardinality is never dropped. Ordinary notifications have no response-count assertion. EOF tails are written as declared and stdin is half-closed before draining all output.

The 60-second exchange and drain limits, 180-second whole lane limit, and 15-minute job limit are unchanged. EOF and ordinary nonzero SDK exits are captured data; timeout, missing pipe EOF, forced process termination, or incomplete capture are failures. Full public differential qualification requires a separately bound HIA capture and complete comparison. Public WAIT, cancellation, remote dispatch, and full asynchronous behavior remain unqualified.

The additional build-proof job only reads the entire retained independent native build proof and publishes actual image identities for the next native domain. It executes no runtime or compiler.
