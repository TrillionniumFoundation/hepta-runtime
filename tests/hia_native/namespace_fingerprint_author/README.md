# Namespace fingerprint implementation preparation

This isolated source version starts the actual namespace-version successor.
It preserves the complete d3d75 target and implements the original fallback
using one HIA owner, imported qualified SHA helpers and a fixed real-libc pump.
The surrounding watcher design and all three original test files are retained.

The workflow freezes every source, assembles the owner, freshly bootstraps the
pinned HIA compiler, compiles the owner and constructs the complete native
adapter/HIA packer sources. It executes no owner semantics and no Rust.
Every child has its original explicit budget; the job remains15 minutes.
Successful and failed source/build streams are fully archived and reread.

Next is actual same-tree native/fresh-Rust comparison with full entries,
owned resources, full buffers and observer-disabled execution, followed by
watcher and ContentWatchSet composition. Source preparation alone does not
qualify those domains or any public audit caller.
