# Public nine-tool composition, revision 2

This isolated candidate connects the ordinary public `text_editor` name to the
complete serial Local four-command gateway. The candidate has **79 physical
HIA images** and **46 private engine descriptor positions**. It is separate
from the repository's production registration and from the full 136-route
replacement.

The actual local native comparison passed in both retained legacy and modern
metadata modes: four processes, 90 complete responses, 33 unchanged response
matches, 30 complete filesystem snapshot matches, two ninth-tool catalogs,
12 TextEditor effect checks and eight subsequent View/cache checks. All four
processes returned zero, with empty stderr and no unconsumed stdout. A separate
read-only reader reconstructed these counts from the complete stored streams,
files, build receipts, HIA images, and final ELF.

The local build compiled six changed/additional images and strictly checked
73 reused images from the final private75 build. It also executed the actual
HIA prefix linker and image packer. The CI recipe defaults to rebuilding all
62 baseline images and all 79 candidate images from source. That new complete
CI recipe has not been run at the time this package was prepared. No original
Rust program was run locally for this composition.

frontend's name dispatch and request preparation, and adds one private edge

body owners, and both callable implementations retain their complete source
bytes. The final public frontend preserves 41 original function ASTs exactly.
The two replaced entry points retain their old bodies under new internal
function names, so all existing eight-route work is delegated to those bodies.
Only the new name is handled by the new preparation function.

After ordinary argument-map decoding and the actual admission owner, the new
route constructs `HTEWGQ02`: operation1, full argument length, resolved
experimental presence and full length, reserved zero, then both complete
spans. Gateway slot37 consumes the already resolved experimental object.
It does not parse raw metadata a second time. The gateway retains typed
parameters → fence → session/configuration/path/policy → caller → result →
release order.

The public transport now creates the actual process TextBody hub before the
session engine and binds its borrow at engine+400. Shutdown releases body and
Create contexts, fence, View and the engine before destroying that hub and the
filesystem hub. The existing callable retains its session context at+408.
No waiter, scheduler, synthetic wake-up or cancellation behavior was added.

## Source-only review and fresh CI execution

The complete package is bound by `source-manifest.json`. A source-only check
does not execute native images or Rust:

```sh
python3 -I -B PACKAGE/scripts/run_native_recipe.py --source PACKAGE --check-only
```

The portable complete native recipe takes checkout paths, not `/home/qq`
artifacts or precompiled images:

```sh
python3 -I -B PACKAGE/scripts/run_native_recipe.py \
  --source PACKAGE \
  --sdk-source REPAIRED_SDK_PACKAGE \
  --hepta PINNED_HEPTA_CHECKOUT \
  --output NEW_OUTPUT
```

The repaired SDK package is published at immutable runtime commit
`b4054165e9b7be63e9309c8223d04131ec4fe31e`, repository path
`tests/hia_native/sdk_target_ci`; its 247-file source manifest is pinned to
`d234cd39fdf8d2e7f3a1fa394f57c69b0d851742c5321d9d6094021a4c748366`.
`ci/workflow.public-nine-native.yml` supplies the exact checkouts, sets runtime
paths in the first step, and has a 90-minute job limit. Individual public
exchanges retain the original 60-second bound. The wrapper does not add an
outer process-group deadline around internally isolated children.

The ordinary public qualifier preserves the old eight-tool workflow and adds
Create, replace, delete, undo-delete, undo-replace and ordinary no-history
behavior in one live public session per mode. It checks complete retained
response bytes, complete file contents and metadata, move inode preservation,
and subsequent View observations. It does not use private fixture selectors
or synthesize handler result text.

For an exported artifact, read-only verification is relocatable:

```sh
python3 -I -B EXTRACTED/recipe-source/scripts/verify_native_nine.py \
  --source EXTRACTED/recipe-source/source \
  --build EXTRACTED/run/public-nine \
  --loop EXTRACTED/run/public-loop \
  --module-map EXTRACTED/module-map.json
```

The reader starts no process, invokes no code image or original executable,
and writes no files. The exporter includes all reused module directories when
needed and reads every archive member back after writing it. Archive integrity
and semantic qualification remain separate statuses.

## Evidence boundaries and preserved failures

The earlier fresh five-original SDK CI and final private75/357-case CI are
separate qualifications. Their counts and target coverage are not inferred
from these 90 public responses. This package does not reclassify historical
RMCP3.4 evidence as full RMCP3.9 coverage.

Target connection identity, actual AsyncRwTransport framing/EOF/shutdown,
and the complete target response owner are not integrated here. The target
CallTool decoder is integrated, while other protocol operations retain the
historical protocol owner. Current CallToolResult constructors and full target
public handler wire behavior therefore remain an explicit next boundary.

The 8MiB Scope/Lease input window, full asynchronous runtime, task registry,
future cancellation, cancellation/fence publication timing, remote execution,
multi-path and directory View, complete 136 routes, production activation and
old-stack removal remain unqualified.

`previous-attempt.json` identifies revision1: its compiled public candidate
passed the retained legacy eight-route prefix but exited111 on its first
TextEditor Create because the old public transport had no TextBody hub.
Revision2 adds that actual lifetime binding. Earlier source-generation and
extracted-executable permission failures also remain retained in the private
working-stage history. No failed record was changed into a PASS.
