# Native persistent namespace Watcher source/build

This independent successor reuses the exact 98,679-byte HIA Watcher from
d5504fbfc03738739f8aac35c87edb640e0a4d55 and its fresh source-build image
e192932db86aeb389243124e59d76a89ca40f0bb499b001bef0c5808fb923bb9.

It adds the actual native inotify/metadata/File reference boundary and an actual
HIA flat-image packer. The recipe freezes source first, fresh-builds the owner,
assembles the fixed native template, compiles and executes the HIA packer with
eight complete-buffer cases, and rereads all compiler/assembler/packer evidence.
No Watcher semantic function or original Rust is executed in this source gate.

The next separate qualification must retain complete original Watcher bodies,
real kernel effects, observed/observer-off calls, full physical buffers, actual
File lifetime, all native ABI refusals, and read-only relocated evidence controls.
Global namespace synchronization, composite ContentWatchSet, fingerprint fallback,
archive store/cache/beginfinish and public routing remain unqualified.

See CALLABLE_ABI.md and the unchanged HIA ABI.md. Final runtime installation rows
will separate latest production code and dependencies from all qualification
fixtures, generated process evidence and retained failures.

packer authoring. V2 retains the complete failure and requires its exact readelf
rows, then adds local aliases at the same exported addresses. No policy or
resource transition is changed; the inverse recovers every prior assembly byte.

complete new source/build passes. Their complete native before/after buffers,

retained and read in a separate process. This does not replace the forthcoming
unchanged original-Rust corpus, observer-off domain, kernel trace or physical
