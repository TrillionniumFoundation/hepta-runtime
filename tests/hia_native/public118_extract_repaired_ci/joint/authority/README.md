# Public91 serial SessionOwner admission

This candidate adds current `SessionOwnerBinding` admission to the qualified
public83 default stdio entry. The public catalog remains the same nine tools.
Its fixed graph contains 91 physical HIA images and 57 global descriptor rows.
The CI recipe performs fresh builds and retains all ordinary comparison domains;
source collection alone is not a qualification result.

## Runtime boundary

The existing G1/G2 owners complete typed request and metadata admission first.
For a tool request, the frontend asks the real installed configuration owner
whether runtime configuration is present. A configured request then invokes the
actual current authority owner through local child 12 / global slot 56. The
fixed request is private opcode 3 with empty headers and payload. The frontend
validates the complete 168-byte response, copies its 80-byte `HROWR001` body into
its own workspace, and continues the existing tool gateway. Disabled runtime
configuration preserves the previous dispatch path.

The native authority loader chooses the stdio fallback using actual OS entropy.
The owner and `authenticated=false` flag come from that session's bound state.
The public request, negotiated peer information, and configuration hash never
supply an authority value. Protocol-only operations leave the authority unbound.
The first configured tool request binds it, including an ordinary typed handler
error; later requests retain that binding until the trusted session is released.
The owner is neither added to public responses nor passed to annotation or audit.

The exact original policy is retained under `target-policy/`, pinned to target
`d3d75c30719db966b004756f610007a7c723729e`. The unchanged current owner-v4 reference
comes from `2058a9103177e23a37c562ee4eddbc0de5e1b5b9` under `owner-reference/`.

The old 56-row boundary and the new 57th row are checked against complete engine
snapshots. Actual release drains the private call, retires its descriptors, wipes
and unmaps the authority allocation, clears +432 and descriptor 56, and accepts
an idempotent second release. The response borrow ends before the next private
call; the frontend keeps its own checked copy. An arbitrary `HROWR001` frame is
not a credential and is never accepted from the public transport.

## Scope that remains open

This is serial stdio session-owner admission. It does not qualify a public HTTP
listener, concurrent bindings, caller annotation, request audit, all SDK response
types, asynchronous task/future/cancellation timing, the complete 136-tool catalog,
or removal of the old runtime. The current original whole-handler comparison flag
remains false. Batch and Bellman routes are not registered by this candidate.
