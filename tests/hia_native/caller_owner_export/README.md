# Current session owner export

This isolated recipe qualifies a new private operation in the existing HIA
authority owner. Operation 3 runs the original authority admission and session
binding first, then projects that bound state to the 80-byte `HROWR001` value.
The complete ABI is in `native/caller_owner_export_abi.md`.

The new source does not reconstruct or reuse the unavailable earlier candidate.
Its author retains all 31 other original functions and proves the inverse of the
small dispatcher change. The source, author and proof were checkpointed before
native compilation. The existing owner-binding function is byte-for-byte the
same HIA graph. The packer changes only the new root's descriptor and actual
image-digest checks. Its other members and syscall adapter remain unchanged.

## Qualification domains

The native state domain has 120 rows, including 15 transport refusals, and retains
all 493 actual child/root entries with complete input, output and workspace
arrays. Equal buffers may share a lossless compressed blob; every reference,
extent and uncompressed byte is reread. The original comparison covers all 105
semantic rows. Output-capacity refusals are native ABI outcomes; the corresponding
original resolver invocation still occurs and its complete bound state is
compared, including a first-call capacity refusal followed by a successful retry.

All eight existing authority groups run unchanged with the new fixed graph.
Their 122 original rows are replayed separately. Two actual syscall-only native
ELF processes execute twelve requests and provide another sixteen lifecycle
rows. Every native and original replay retains its original 60-second limit.

The fresh Rust 1.95 reference builds only in CI. It uses the exact current
`d3d75c30719db966b004756f610007a7c723729e` caller scope and crypto owners, original
HTTP authentication and owner-entropy slices, RMCP 3.9.0 and Tokio 1.53.3. It uses
actual `RequestContext` objects and original middleware. The entire generated
source and all actual locked registry archives and source checks are retained.
The stdio resolver receives the observed private native fallback as an explicit
fixture input; this is not a claim that two independently generated random
owners match. A missing HTTP extension is a direct fixture and does not qualify
optional HTTP startup or the current HTTP listener.

`qualify.py --phase all` performs fresh HIA compilation, all native domains,
fresh original compilation and the three original replays, sixteen reader
mutations and two independent physical reader copies. `--phase verify` reads
and compares the existing result under write, process and native-mapping
rejection; it never rewrites a report. Its full byte and metadata snapshots must
remain identical. Bootstrap fixed-point evidence is explicitly separate from
Hepta's aggregate matching-source cold qualification.

## Reuse by tool bodies

| Boundary | Reusable value or operation | Remaining composition work |
| --- | --- | --- |
| Trusted authority and serial session state | Existing admission and binding, followed by operation 3's complete owner and authenticated flag | Connect only the actual current CALL's borrowed response; reject any public request field purporting to be this private value |
| Scoped request and operation stores | The same complete owner key used by current target wrappers | Preserve each store's permits, bounds, lifecycle and error ordering; this recipe does not execute those stores |
| `OwnerScope::annotate` component | The independently qualified annotation owner can consume the bound flag and complete metadata result | A fixed private caller edge must validate this result's status and exact 80-byte extent before handing it to annotation; that joined graph is not qualified here |
| Crypto selection | Existing operation 2 and its complete original comparisons are retained | Owner hashes are not crypto keys; callers must keep using the private crypto capability |
| SDK request context and transport | Real current Rust contexts qualify the finite reference side | Full HTTP startup, public routing, concurrent `Arc<Mutex<...>>` behaviour and connection ownership need their own joined qualification |

No public handler, production activation, global runtime replacement or removal
of the old stack is claimed by this component.
