# Native pinned-anchor source preparation

This isolated successor implements the real retained legacy-anchor dependency required by
request_audit persistence. It reuses the exact audit JSON Anchor codec and byte-access
helpers from the closed record-I/O owner. It leaves every prior qualified source unchanged.

Run source_check.py for pure source admission. The pinned CI preparation runs author_owner,
fresh Hepta fixed-point bootstrap and image compilation, then actual GAS source assembly
and HIA packer source generation. It does not invoke the new owner or the new packer, and
does not run Rust. All generated sources, full compiler receipts, complete compiler source,
assembler streams and failures are archived in full. No expected output is an author input.
