# Actual current publisher asynchronous reference domain

This isolated package captures 30 ordinary lifecycle scenarios through the unchanged target publisher and the actual current SDK. It does not install production sources and does not qualify the native asynchronous implementation.

## Immutable original implementation

The exact original observer was freshly compiled by Rust 1.95.0 in commit `d18edc08ddf7962bc23ad5bf9d8997ae29eaac6c`, run `44066500690`. Its complete archive, all 120 original source spans, 47 compiler inputs, 86 exact target registry crates and all 4,401 archived registry files are restored and read before any application run. The observer binary and full ZIP/TAR identities are fixed in DEPENDENCY.json. This package does not rerun Cargo or change those original Rust sources.

The original text publisher still performs its real spawn_blocking call and actual file publication. A test-owned exclusive directory flock pauses the actual blocking body. Reading this process's own /proc task syscall records binds each observed wait to that same held directory device/inode. No original implementation instruction or worker result is replaced.

## Thirty input-only scenarios

DOMAIN.json and recipe/input_domain.py define 22 public sessions (11 lifecycle scenarios in each legacy and modern protocol mode) and eight direct future scenarios. The public modes cover ordinary completion, cancellation notifications, unknown and already completed IDs, ID reuse while an older generation remains pending, two requests in one session, two sessions, input EOF, complete transport closure and EOF after completion. The direct modes distinguish an unpolled future from a started or queued blocking body, actual future Drop from notification cancellation, and a later independent operation after Drop.

Queued cases use one explicitly configured blocking thread occupied by an owned Condvar task until the capture releases it. They do not claim this test capacity is the production pool policy. Started cases are admitted only after the actual publisher worker is observed inside flock. The observer number is not an SDK request identity or an authorization token.

Only requests, controls, fixture inputs and observation points are supplied. No expected SDK wire or expected publication result is manufactured. Complete actual response/error lines, EOF terminal observations, future enter/return/Drop events, both caches, history, lock observations, session state and every stable filesystem snapshot are retained. The Runtime Drop is actual and waits for detached blocking work.

## Execution and evidence

Each original process keeps its original 180-second limit and every exchange its 60-second limit. Each CI job is limited to 15 minutes. The independent pure reader and physical-control process each retain a 180-second limit. There is no new outer process-group timeout around the application runner that could silently leave its independently grouped original process alive.

The capture uses the entire retained Process class text and AST; AUTHOR.json records the exact origin and unchanged helper pins. The physical reader domain has eight real mutations and two complete relocated copies. Coherent mutations resign stream hashes and indexes, so the reader must reject the actual inconsistent semantic observation rather than only a stale hash.

The export includes all regular files and all directories, including empty fixture directories, with exact modes, mtime and xattr observations. Uploaded evidence is restored into a new root and fully checked again. The independent reader executes no HIA or Rust, rejects writes, process creation, mmap, ctypes and foreign reads, and proves the complete evidence tree's bytes and metadata unchanged before/after.

## Commands

Run only the capture command in the frozen CI; source and read commands are pure source/evidence operations.

```sh
python3 -I -S -B recipe/entry.py source
python3 -I -S -B recipe/entry.py capture --output /fresh/capture
timeout 180s python3 -I -S -B recipe/entry.py read --capture /fresh/capture --output /fresh/capture-readonly.json
python3 -I -S -B recipe/archive.py pack --source . --capture /fresh/capture --output /fresh/export --driver-prefix /fresh/driver
```

A completed original-reference result is a reference qualification only. Native asynchronous publication, shared WAIT integration, full SDK, all 136 public handlers and old-stack removal remain false until their separate actual comparisons close. Existing failed captures and unknown processes are not replaced or replayed by this package.
