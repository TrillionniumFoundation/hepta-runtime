# Native audit record I/O callable — frozen private candidate

The fixed SysV AMD64 adapter calls the exact qualified audit_record_io and
audit_json HIA images. It performs every emitted libc effect, owns descriptor
and directory-stream tokens, and returns the unchanged HIA terminal frame.
Python is an explicit fixture/observer only; it does not choose an effect or
supply an ACK. The optional callback is absent in the second complete cohort.

The two semantic images remain 295,103 bytes / 3b290dab82a2c60982a7af947562a4cf7aa407e9399c0d877640354c13112664
and 161,260 bytes / 76122331b305e654b6175a3d0a975d080815ee1cfcf542ea837d8aecdb83b2fc.
The 6,304-byte GAS adapter and generated HIA packer source were first assembled
and frozen in author CI 44048463978. That author gate executed no HIA semantics
or Rust. This package's runtime qualification is pending its new CI.

## Entry points and budgets

run_callable.py performs the new explicit native capture. qualify_callable.py
records semantic, controls, and final pure-reader phases separately.
reader_callable_cli.py --phase verify only compares the existing final proof;
it writes no file and maps or executes no native code. Its complete result is
sent to stdout after the guard.

Fresh build: 900 seconds. Each ordinary native cohort and each controls/reader
process: 180 seconds. Assembler/tool phases: 60 seconds. CI job: 15 minutes.
These budgets are unchanged. All new semantic execution is CI-only.

## Scope

This is a private ordinary record I/O transport qualification. It does not
qualify request_audit archive namespaces, HOT_CACHE, begin/finish callers,
async scheduling, public handlers, or the whole runtime. No claim is made that
the fixed Python guard is a universal security sandbox. It protects these
source-bound readers and their retained artifact roots.
