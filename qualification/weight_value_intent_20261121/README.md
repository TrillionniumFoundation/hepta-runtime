It authenticates the original checkpoint with the parent semantic/source adapters, checks all 196 old and replacement F64 bit patterns, derives an isolated in-memory preview, and admits an externally pinned, typed evaluator record. Its result is **KEEP_ORIGINAL_AND_STOP**.

## Source and parameter contract

The reviewed main revision is `d3d75c30719db966b004756f610007a7c723729e`. The inherited semantic adapter and continuation source reader bind the compressed checkpoint, its exact decoded JSON bytes, the reviewed profile, original task/forward/planning/arithmetic sources, and all protected law/task metadata. They validate the actual C85→48→4 structure and stored finite transition tables.

Editable coordinates are the 192 row-major `network.w2` entries followed by four `network.b2` entries. Q-only permits output rows 0–2; Belief-only permits row 3; joint permits all rows. The hidden layer and protected physics/task fields remain fixed by construction. Old bits distinguish positive and negative zero. Replacement values must be finite; there is no F64-to-F32 conversion.

The exact shared constraint is:

`4 × Σ196(new − original)² ≤ ΣQ147(original)²`

Q147 consists of the first three weight rows and the first three biases. All terms use the exact represented binary64 values. The integer arithmetic adapts main's existing weight_norm algorithm to 66 u64 limbs. Finite F64 differences, 196 squared terms, and the factor four fit strictly below 2^4208; capacity is 4224 bits. Witnesses use integer units 2^-2148. This definition is the exact mathematical half-norm radius; it does not claim bitwise equivalence with a prior rounded F64 norm and squared radius.

## Evaluator admission is a separate boundary

The external review contract binds the candidate ID, row mask, original semantic identity, producer, protocol, evaluator, full-state dataset manifest and evaluator-record bytes. Typed records permit only full-state own-law DAG expected task utility for the fixed target sign(X_deadline6), including early submission. Current-tick endpoint scores and financial PnL are rejected.

Exposed TRAIN generation, selection and audit are distinct roles. A declared sealed own-law confirmation additionally requires different finalist and post-freeze sample seal hashes in the review contract. These hashes do not prove chronology, source meaning, randomness, canonical ownership, or sample independence. The output explicitly sets sealed_sample_independence_verified and independent_financial_labels_verified to false. Independent source/evidence review supplies any stronger qualification; this crate does not rerun the DAG or independently recompute the supplied gain.

A record must report completed work and finite values within the external work/CPU bounds. These are admission checks on saved evidence, not a production runtime budget owner or a new scientific evaluation.

## Existing owner and why the answer is KEEP

Current main's rea_model parser/read owner and weight_tensor descriptor admit safetensors F32, F16 and BF16 edits. The existing weight_artifact / weight_artifact_cohort and weight_guard_journal retain artifact and recovery responsibilities. The full JSON/F64 C85 model is unsupported by that path. The research crate does not lower precision, construct fake safetensors descriptors, invoke a production patch, register another route, or add a competing owner.

For the reviewed owner revision, the result is UNSUPPORTED_JSON_F64. An unreviewed owner revision returns UNREVIEWED_OWNER_REVISION. Both keep the original. A supplied own-law gain cannot override capability admission or establish net serving value; there is no general NDU optimization without a valid cost/value contract.

The preview is an owned memory clone. The original has no mutable API, and the CLI re-reads and compares the original gzip bytes after each review. Discarding the clone is not evidence that the production commit/restore path or crash recovery has been integrated or tested. No active checkpoint, optimizer, service, pointer or trading state is changed.
