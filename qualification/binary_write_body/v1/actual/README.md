# Locked binary-write composition qualification

This frozen qualification composes the unchanged 43-function HIA write body with
the qualified publication, read67, stat, metadata, codec, strict Base64,
formatter34 and process-wide entropy implementations. Production ELF identity is
bound in BUILD_REUSE.json. Author/build stages execute zero write applications.

DOMAIN.json freezes 101 distinct actual inputs, 103 invocations per side, 35
groups and the physical reader controls before any original or native invocation.
Every admitted case runs once in its own owned process per side, with the two
shared-cache cases using two independent contexts in one process. Fixed before
effect notifications carry zero-only acknowledgements. Real BPF filters,
RLIMIT_FSIZE and separately owned filesystem actors supply the declared faults.

The unmodified original helper functions and entire original locked suite are
AST-bound to the exact target commit. Passive ptrace retains every actual entry,
exit, complete observed buffer and delivered signal, including C FileIO effects.
The observer permits no register/memory write or result replacement. Root native
contexts are identified by complete double read of actual guarded mappings with
process_vm_readv; no context address is inferred or fabricated.

Pure readers consume complete process streams, HIA input/output/workspaces,
child loans, actual contexts, kernel observations, EOF descriptor survivors,
orphan pages and filesystem state. Native effect resumes must match the actual
kernel returns and bytes. Result versions are checked against each process's
own real stat values before cross-process identity normalization. UUID stage
names are normalized only after deriving them from their own real entropy.

Captured results are PASS, FAIL or UNKNOWN. No completed or UNKNOWN application
is replayed. Pure-reader failures retain all completed application evidence.
Before removing expanded build copies, every logical file/byte/mode/directory
is compared to the retained complete original ZIP and a retirement proof saved.
All actual/failed evidence and physical negative/relocation copies are archived.

This is the borrowed-parent private write body qualification. Public routing,
parent path policy, SSH, upload and inode_patch remain separate integration
obligations. It does not assert whole-runtime replacement.
