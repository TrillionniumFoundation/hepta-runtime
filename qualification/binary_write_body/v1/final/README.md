# Binary write final private component

This directory binds the single qualified HIA locked write implementation, fixed
mechanical callable and exact installation documentation. The source is unchanged
from the zero-application native build. HANDOFF.json binds all original/native
captures, retained failures and subsequent independent reads of every uploaded
archive. INSTALL.json lists five final production files; fixture, authoring and
qualification programs are excluded from installation.

The 101-case domain completed 103 semantic invocations per implementation in
202 isolated processes. All 35 independent upload readers passed with no new
application or completed-control execution. Six cases deliberately disable the
observer; their context, syscall, filesystem and lifetime evidence remains real.
The public caller still owns path authorization, parent close, typed JSON, async
cancellation, Remote/SSH transport and namespace/cache integration.

Use one process orphan pool and one serialized entropy context. Never recreate
entropy per request, close or duplicate an orphan, synthesize syscall returns,
truncate child spans, install the private carrier or reinterpret u64 source
numbers through a binary64 JSON roundtrip. Replace caller bindings only after
the complete caller has been qualified.
