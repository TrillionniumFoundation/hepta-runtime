# HIA binary write source author

This immutable package authors the locked borrowed-parent binary write owner.
It retains unchanged qualified read-body utilities and preserves their complete
IR under explicit relocation, then admits the new graph to the fixed Hepta
function/block/operation/SSA limits. The source author does not compile or invoke
a native HIA module, execute target Python/Rust, or touch application files.

The ABI defines the actual lock, expected, decode, UUID, temp write, publish,
fingerprint and cleanup chain. Native linking and actual reference qualification
follow separately. Parent acquisition, typed request admission, SSH, public
routes and default graph installation are caller integrations still required.
No existing production route or old runtime is removed by this package.

Reference source is the exact target binary_file.py and CPython v3.12.3 sources.
Qualified child handoffs bind stat/codec, strict Base64, process entropy,
publish_at, read67 and literal error34; copying those references does not assert
that this new composition has been qualified. Every source byte is frozen and
fully reread before the source-only CI branch is created.
