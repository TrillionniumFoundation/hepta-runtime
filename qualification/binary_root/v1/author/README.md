# Installed binary configured-root owner author

This source authors operation 9 on the exact installed configuration span owner. It retains all existing configuration startup, path policy and op8 growth functions. The query checks installed configuration, exact configured host name, operator mode, original alias-based remote path policy, then longest matching raw prefix of the originally named host in original order. Equal-length matches select the last entry. Error payloads reproduce the target functions in target/config.rs and target/binary.rs.

The author runs only the frozen Python assembly tooling. It does not compile or execute HIA, run Rust, install a public route or claim semantic qualification. All authored outputs and complete author process streams are exported. Native build, actual installed startup, original function comparisons, capacity controls and full archive readback must be separately frozen and qualified before use.
