# Fixed native boundary build

The fixed native exports are binary_entropy_create(callback, opaque, shared_process_pool), binary_entropy_invoke(context, immutable_start_packet, length), and binary_entropy_release(context). Create returns a process-lifetime 4,096-byte context with four private guarded mappings. There is deliberately no public destroy/reset export; the graph creates exactly one context and serializes its applications. Invocation admission atomically claims the context; the PID and pool binding are checked. Release only retires the result loan, while preserving the HIA workspace, cache FD and sticky random-interface status.

The capability table contains getrandom16, open of the fixed /dev/urandom path, fstat of owned tokens, candidate close, cached read and explicit pool transfer. The native ledger rejects unowned or foreign FDs and binds read/transfer to the HIA-declared cache; close is admitted only for its distinct candidate. All branches selecting an operation, error and retry are HIA. The input buffer cannot select an FD, path, callback, code pointer or image. The callback can observe full actual input/work/output buffers and capability replies; a nonzero callback return poisons the context and never substitutes an effect result.

The build compiles three HIA sources (body, ELF linker and image packer), links actual zero-relocation GAS bytes, then packs one runtime HIA image. The tiny fixture entry only returns; qualification will admit the complete immutable ELF and call its fixed position-independent exports. That Python/native harness is excluded from production installation. The same callable assembly and HIA image can be statically composed into the final native runtime graph without Python or libc.

This build gate executes zero entropy or reference applications. It reuses and fully verifies the retained actual B3 archive, includes complete compiler source and all compilation/link/pack buffers, tests four actual corruptions and two full relocations under write/execution denial, and preserves all files, modes and directories before retiring duplicate working copies.
