# Qualified private binary write composition

This isolated successor to PR137 connects the real HIA request adapter, the
unchanged HIA call planner, and the qualified HIA parent/body graph in the same
process. It preserves their exact complete requests and results, borrowed
lifetimes, filesystem effects, kernel calls, error ordering and process orphan
ownership. The graph has twelve runtime images; the actual linker and packer
bring its source-bound member inventory to fourteen.

The fixed mechanical connection calls the parent only after the adapter has
compared the entire actual planner result and emitted a complete `HBPWQ001`
packet. Application decisions remain in the existing HIA owners. The result is
the complete original `HBPWR001` parent frame or `HBWAR001` adapter mismatch;
there is no host reconstruction of JSON, application errors or child results.
The callable ABI and remaining failure boundaries are in [source/ABI.md](source/ABI.md).

This directory installs no public route or production carrier. The product
inherited from PR137 retains all thirteen public native tools out of the
original 136-tool target, all 71 slots, and its 118 direct plus eight packed
images. No existing product source, handler, workflow, budget or completion
flag changes in this PR.
