This package authors the original bounded multi-file body in HIA. It preserves complete target source bytes, copied helper ASTs, the retained UTF-8 validation IR, two independent unchanged directory contexts, process-orphan ownership, strict UTF-8 diagnostics and the full MCP byte budget. Source generation is the only activity in the accompanying workflow: no native module or original application is executed. Runtime files, Linux effects, typed/public host policy and SSH transport must pass their own actual comparisons before installation.
