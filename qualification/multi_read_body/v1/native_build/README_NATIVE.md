This package is a source-owned five-image multi-file body and six-image private observation ELF. It reproduces both HIA authors, compiles exclusively with the copied/reverified B3, links with the actual HIA linker and packs with the actual HIA image packer. The accompanying native build makes zero application calls. Complete build bytes, four physical refusals, two relocations and eleven read-only guards are retained. Actual UTF-8, filesystem, Remote host policy, SSH transport and public route gates remain separate and must not be inferred from compilation.
