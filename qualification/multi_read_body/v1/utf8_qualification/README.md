# Actual strict UTF-8 leaf qualification

This package calls the original frozen CPython expression and the exact packed HIA leaf in separate owned processes. It retains complete original values/errors, complete native input/output/work buffers, raw process streams, EOF witnesses, eight physical corruptions, and two full relocations per lane. The source and existing build are admitted before applications. No original result is an implementation input.

This is one private dependency of multi_read_body. It does not qualify filesystem effects, named-host routing, SSH, the public read_multiple_files handler, or any whole-runtime replacement. Failed captures are never overwritten or replayed by a reader repair.
