# File_info native composition build

The frozen info HIA owner is composed with the unchanged qualified borrowed-parent fingerprint, Linux metadata, stat/codec and dual-structure error owners. Native adapters supply only fixed capability syscalls, immutable child selection, full buffer transfer, explicit output loans and the shared process-lifetime orphan primitive. The same c811 orphan source is shared with the writer lane.

The build copies and completely reverifies the already retained B3 fixed point. It compiles eight HIA owners (six runtime images plus linker and packer), runs the actual HIA linker and packer, then reads every generated compiler buffer, source, native byte, patch and output. Four physical corruptions and two complete relocations are checked under the original strict read guard. No info application or original Python/Rust handler executes in this build.

NATIVE_ABI.md defines the later private actual-platform domain, including real parent/file FD0, full child state, structured errors, kernel fstat failure and process-lifetime orphan inventory. Those capabilities are source-only until separately executed and compared. All prior author failures remain retained. The main runtime and the shared read67, metadata63, parent and writer sources are not modified.
