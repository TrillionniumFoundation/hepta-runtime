# Remote binary request projection and fixed ELF bootstrap source

These two new HIA modules are source candidates. They add no public route or private application qualification. The raw HIA source is authored in CI, rendered and reassembled exactly, then frozen before compilation.

## Fixed JSON field projection

binary_remote_fields f0 receives a 64-byte HBRJP001 header, the complete original JSON bytes and the complete actual JSON-items child result. JSON length is at8, items length at16, words24..56 are zero. JSON byte length is at most6,291,456; this is the dependency's private bound and still needs a public admissible-input proof. Only the trusted native graph can provide child results. Actual UTF-8/16/32 decoding and JSON parsing remain separate HIA children; no host interpreter supplies fields.

A valid fixed call-plan object produces HRBFQ001: a512-byte header, the unchanged original JSON and concatenated decoded UTF-8 string fields. Operation at8 is1info,2read,3write,4upload_chunk,5upload_commit,6upload_abort,7inode_patch,8private_read. Original JSON byte length is16, total payload length24, present-field bitmap32. Sixteen24-byte descriptors start64: kind0None,1string,2u64,3bool; the next word is absolute string offset or scalar value, followed by string byte length or0. Ordered descriptor keys are root,path,op,expected_version,data_base64,offset,limit,upload_id,size,sha256,action,host,acknowledge_non_atomic,preserve_special_bits,transaction_id,expected_sha256. Remaining header bytes are zero. Exact per-operation field masks are frozen in WIRE.json and match the prior qualified call-plan output. This is a private generated-request protocol; arbitrary extra keys, wrong types, negative or overflowing integers and non-UTF-8 strings are private framing failures.

Complete HPYJSR01 kind3 diagnostics pass through HBRER001 kind3 with the original complete class-prefixed UTF-8 bytes at64 and length56. The module never rewrites them as ValueError. Valid returns are whole response extents. u32 -1 is private framing refusal, -3 short work and -2 short output. Required work is512+original JSON bytes+items response bytes. Output is unchanged on refusal. Input is immutable; after initial admission work is scratch, including later protocol or output-capacity refusal. Final output suffix bytes remain unchanged. Successful fixed requests use no host-generated expected values.

## Fixed remote bootstrap

ssh_native_bootstrap accepts exactly64 bytes: HSSBQ001, trusted compiled ELF byte length at8, and zero remaining words. Size is1..0xfffeffff. It emits HSSBR001 with size8, full65536-byte blocks16, remainder24 and command byte length56, then the complete fixed shell text. Work minimum4096; refusals are u32 -1/-3/-2 and never change output. The size is supplied only by the graph's installed actual ELF, never by tool arguments.

All text is generated by HIA from frozen literals and exact decimal integers. The shell uses a private mktemp directory, restrictive umask, exact GNU dd full blocks plus remainder, full resulting file-size check, chmod and the sole helper entry. It reads no request bytes while installing the ELF. The helper runs with explicit original stdin inheritance and an explicit wait; EXIT/signal traps clean the private executable and directory. Native helper entry must set PR_SET_PDEATHSIG(SIGKILL) with the parent-race check before any business operation. The shell never re-signals a potentially reaped PID. Remote parsing, path authorization, file IO, errors and policy are HIA-owned.

Compilation executes zero applications. Actual qualification must use only CI loopback sshd and temporary accounts/directories, with short reads, complete ELF boundary, no stdin overread, exec failure, original30-second request deadline, local original-child kill/reap, remote parent-death behavior, successful and failed cleanup evidence. No real configured user host is contacted. JSON-items remains a separately pending dependency. Public caller budgets, transport/input bounds, observation cache, audit, helper composition and all public route installation remain pending.
