# HIA literal error source author

Adds the three typed literal errors needed by the qualified strict Base64 and process-lifetime entropy primitives. The source author checks the full qualified 32-function path-error baseline, generates a 34-function successor through the pinned Hepta source tools, and proves every retained function is exact IR after a single entry relocation. Application and native compiler calls remain zero during authoring.

Legacy accepted inputs remain unchanged. The three newly accepted HBRDS001 literal classes are an explicit extension of previously invalid input space and require their own original CPython qualification. This package does not mark any public runtime handler complete.
