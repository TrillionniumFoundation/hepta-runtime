# Final literal formatter candidate qualification

This frozen source package qualifies the 34-function HIA formatter produced by the retained-B3 build. All 32 original functions and all platform-data bytes remain unchanged. The new HBRDS001 literal classes are Error (15), NotImplementedError (16), and RuntimeError (17).

The retained path-error archive supplies all 21,901 already completed original diagnostic results. Its complete ZIP, TAR objects, logical files, modes, source and previous native/control evidence are admitted before any new application. None of those original or old native applications is replayed.

The candidate executes exactly 435 new CPython literal diagnostics and 23,591 new HIA calls: 22,336 semantic calls and 1,255 private boundaries. The original constructor is CPython 3.12.3, including actual binascii.Error. Each application worker has a 60-second deadline. All full messages, raw input frames, return values, output spans, workspace spans and arena tails are retained. Three classes each cover every Unicode scalar; limits include one MiB plus one byte.

The four runtime files are copied byte for byte from the full qualified build. This package invokes no compiler or bootstrap. Admission and independent readers execute no native or original applications. Every pure reader is bounded to 180 seconds and rejects mutation, execution, foreign reads and foreign capabilities with eleven probes. Eight physical mutations honestly reseal stream metadata where appropriate, and two complete source/application/runtime relocations are independently read against the retained originals. All expanded copies remain until archive equality has been established.

FAIL and UNKNOWN are distinct. A completed or unknown application group is never automatically replayed. This is a private primitive qualification; public write/upload routes and the whole runtime remain unfinished.
