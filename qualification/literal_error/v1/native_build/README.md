# Native HIA literal error build

Compiles the generated 34-function literal_error HIA source once using the complete retained B1=B2=B3 compiler archive. No seed or bootstrap generation runs. This gate invokes no formatter or original application. It retains the full author outputs, compiler source closure, copied bootstrap, raw compilation input/output/request/receipt and image, then reads all retained bytes under eleven capability-denial guards.

The source remains unqualified for application semantics until the frozen original/new-native domain and independent uploaded readers pass. All previous accepted path-error inputs and the new Error, NotImplementedError and RuntimeError literals must be checked before runtime integration.
