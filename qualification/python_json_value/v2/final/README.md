# Qualified HIA Python JSON values

This directory is the final private JSON value component. The two native source files are the exact tested HIA and raw composition. ABI.md defines the stable call interface; UNIQUE_INSTALL_ROWS.json is the sole three-file installation list. Full runtime integration is a separate pending gate.

The native image has 110 functions, 5,312 operations and 1,101 blocks. The main domain completed 6,197 original and 6,227 HIA calls, including 30 private protocol controls. Another 1,299 previously unexecuted HIA calls matched completed original deep-recursion profiles. All 18 uploaded-reading groups passed with zero application replay. The main evidence also passed eight physical rejection controls and two relocations.

FINAL_HANDOFF.json records the exact source/image/CI identities and limits. SOURCE_ROWS.json binds every original profile, author, build, producer and independent reader source. evidence/ retains the complete qualification checkpoints, including the initial zero-application reader failure. No pseudocode or source author is installed as a runtime implementation.

The byte-to-Unicode decoder is the separate qualified python_json_bytes component. Production callers must bind their actual C recursion budgets and maintain the full class-prefixed diagnostic payloads. Upload, inode, public graph and remote transport are not certified by this component's private gate.
