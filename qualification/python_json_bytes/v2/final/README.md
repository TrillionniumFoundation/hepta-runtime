# HIA Python JSON byte decoding

This directory contains the sole final decoder source, composition, ABI and installation index. The HIA code performs JSON byte encoding detection and surrogatepass decoding with no host codec dependency.

All four actual capture shards and all four independent uploaded-archive reads passed. There were 100,640 original calls, 100,670 HIA calls, 30 private boundary controls, eight physical evidence refusals and two successful relocations. Independent reading did not replay any application or control. HANDOFF.json binds the complete source, build, full captures, archives and independent proofs.

Install only the entries in INSTALL.json. Authoring sources and private qualification fixtures are retained in their pinned evidence commits and are excluded from this production installation. JSON syntax/value behavior and complete upload/inode operations are separate owners and remain necessary for public integration.
