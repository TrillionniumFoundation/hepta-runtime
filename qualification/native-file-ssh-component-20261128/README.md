# Configured native file SSH component evidence

This preserves the real component build, initial uninitialized rejection,
repaired protocol handshake, installed configuration to real SSH execution,
and private response decoder controls. It does not assert default public
transport, cancellation, original error formatting, or whole-runtime closure.

The Desktop archive holds 712 complete files / 81,995,840 logical bytes;
233 recorded physical input bindings all match, with no input mismatch.
The Mac archive holds 197 files / 8,702,173 bytes and also contains the
first Mac collector failure. Both archives were independently read in full
and every object digest and path mapping verified. Original physical files
remain in their owned directories; no cleanup was performed.

CAS manifests are inside each archive and also provided separately. Restore
objects by their SHA256 and use the path records for bytes, mode, file kind,
and captured metadata. Neither archive executes its contents. The component
scope and exact wire contracts are documented in native/file_ssh_transport_abi.md.
