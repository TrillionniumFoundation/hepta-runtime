## Source and evidence contract

qualified-product-inputs.json is the exact current construction's input map.
All bytes are checked against the staged Git blobs before commit. Git mode is
checked against the executable-bit projection of the captured POSIX mode. Git
does not encode the difference between non-executable 0600 and 0644; the exact
physical permission modes remain in the qualified input map and complete CAS.
The initial preparation incorrectly compared those representations directly;
that failed check is preserved, and no qualified source or test was changed.
The default production sources are listed independently in source-registration.json.

The Desktop archive is a content-addressed tar. Its manifest maps every complete
selected file and captured dependency to an exact object, size and mode.
All 966 objects and all 1,799 members were verified independently on both hosts.
The Mac archive contains the complete preparation, transport receipts, failures
and exact executed code arguments. Archives are split only for Git storage;
verify_evidence.py concatenates them in declared order and verifies every byte
and member.

The actual full default graph and all test inputs are retained. No test budget,
old method body, assertion, HIA compiler capacity, image hash or stream bound was
relaxed. The three small runtime terminal wrappers and explicit final destroy
are separate from the retained original mechanical bodies.
