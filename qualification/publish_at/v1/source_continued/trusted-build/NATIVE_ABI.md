# Fixed Linux publication callable

publish_at_create(callback, callback_context, process_orphans_pool) creates a guarded context and a fixed metadata child. The supplied pool is the c811 same-PID primitive shared by all contexts. publish_at_invoke(context, borrowed_parent_fd, packet, length) accepts the exact HPUBQ001 contract in ABI.md. Caller FD data is zero in the wire and injected only from the trusted argument.

Return64 borrows the complete HPUBR001 response at context+104 with extent context+168 and state2. release consumes the loan; destroy refuses active or borrowed contexts. The parent is never opened, duplicated, closed or orphaned by this component. Native owned slots256..319 initialize to -1; every successful owned open creates one real token, every close retires its one token, and ORPHAN_OWNED retires only after actual pool ACK0. Fatal private resource/protocol failures keep the remaining operable tokens for teardown. Pool records are never traversed for close and have no reset API.

The common4096-byte context layout is the same fixed pump: body16/stat24, callback40/context48, state56; input64/72/80, work88/96, output104/112, resume120/128, stat output136/work144; borrowed response168, actual return176, owned count184, generation192; current input200/208, sequence216/op224, actual result232/payload240, body call count248, eight actual FD slots256..319, stat entry320/output/work extents328/336. Borrowed parent344/active352, nested child360/type368, shared pool376, reserved384zero, metadata context392, cumulative orphan transfers400. Parent FD0 is valid and distinguished by its active bit.

The production state machine owns every version comparison, regular/private check, retry, metadata preserve decision, exception choice and finally-close order. The native switch is limited to the ten fixed operations in ABI.md. In particular, linkat(265), renameat(264) and unlinkat(263) use the exact injected parent and validated NUL-terminated leaf payloads. Metadata mode3 uses the two actual owned descriptors; complete metadata output is copied before explicit child release. Stat and codec remain actual qualified HIA.

The fixed image order is body,metadata,codec,stat,error. The formatter is qualified path_error32, accepting all HBRDS/HMDSR/HOSER structured frames. Exactly five runtime images, seven actual compilations including HIA linker/packer, and five trusted call patches form the ELF. A complete retained actual B3 is copied and verified; no new bootstrap seed or application executes during this build.

The private fixture uses length-prefixed HPUBFQ01/HPUBFR01 frames with the existing64-byte command header and two slots. The restriction stays until OS process exit.

Complete journals are HPUBJR01 and HMDTJR01 with128-byte common headers, exact full input/work/output spans, growth spans and actual effects. HPUBHK01/HMDTHK01 require zero-only ACKs before real calls. Event15 records a complete child context before child release. HPUBER01 records all formatter input/work/output bytes and return. Observers may coordinate a real mutation actor but may not substitute bytes or results. EOF releases outstanding responses, destroys idle contexts and closes only fixture-owned parent descriptors; the shared orphan pool remains until process exit.
