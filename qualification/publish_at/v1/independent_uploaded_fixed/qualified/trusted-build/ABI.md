# Borrowed parent publication owner

The complete Linux publish(fd, name, temp, prior) policy is HIA. The native boundary executes only fixed descriptor-relative operations and the exact qualified stat-version/metadata child images. No caller selects executable addresses, syscall numbers or FD authority. The caller lends a live parent directory throughout the synchronous invocation. Names are UTF-8 leaf components with no slash; embedded NUL remains data until the corresponding original open would raise ValueError.

HPUBQ001 uses a96-byte header: command8 (1start/2resume), sequence16, start mode1 or raw signed result24, trusted borrowed parent FD32, name length40, temporary-name length48, prior length56, prior-present flag64, zero72/80, payload length88. The external start parent word must be zero and is injected from the callable's trusted argument. Payload is name+temporary-name+prior UTF-8. Resume requires exact outstanding sequence, zero32..80 and the full response. Negative syscall results are -4095..-1 with no payload. Reply payload is at most1MiB. Same-call capacity retry preserves and matches the accepted input and result exactly.

HPUBR001 uses a64-byte header: kind8 (0complete/1fixed effect/2child/3error/4work growth/5output growth), sequence16, op24, arguments32/40/48, payload length56. Success has empty payload. Error contains one complete HBRDS001, HMDSR001 or HOSER001 frame for the qualified32-function formatter. There is no Python/libc formatter in the native implementation.

Fixed effects:1openat parent O_RDONLY|O_NOFOLLOW|O_NONBLOCK|O_CLOEXEC;2fstat of an owned FD;3close owned FD;4ORPHAN_OWNED;5geteuid;6openat parent O_RDWR with the same mandatory flags;7fsync owned FD or the exact borrowed parent;8linkat temporary name to destination with flags0;9unlinkat temporary name with flags0;10renameat temporary name to destination. Open payloads are exactly one NUL-terminated name. Link/rename payload is destination+NUL+temporary+NUL, and arguments b/c are their respective complete extents; the actual syscall order remains temporary -> destination. HIA retries EINTR only for open/fstat/fsync, matching CPython. Link/rename/unlink/close are not retried.

ORPHAN_OWNED is a fixed capability transfer, not an OS call. It appends the actual owned FD, origin context and invocation generation to the shared same-process orphan pool. Only successful ACK0 clears the callable's operable ownership token. There is no close, dup or reopen. A failed append remains a private resource failure with the token retained. Orphan records and kernel descriptors survive context release/destruction and are reclaimed only at whole-process exit.

Child op1 executes actual HSTVER01 stat-version HIA on72 bytes. Child op2 invokes the qualified63-function file_metadata preserve callable with the already-owned source and temporary FDs, exact96-byte HMDTQ001 mode3 request and no external FD words. The complete metadata result/error frame is returned before releasing the child response. Its summary JSON may be up to900,000 bytes; parent reply capacity is1MiB. Metadata's fixed codec remains actual HIA.

Order is first expected/current, private temporary open, optional source version and metadata preserve, source finally-close, temporary fsync and finally-close, second expected/current, link+unlink or replace, parent fsync. Every current() call closes its successful regular-file open and catches FileNotFoundError from its whole body, including the close. Each regular() first-fstat failure transfers its leaked FD to the process pool, preserving original lifetime. Later fstat errors close inside the original finally scope. Close errors override earlier exceptions in original order. Temporary cleanup and outer file locks belong to the write/upload caller.
