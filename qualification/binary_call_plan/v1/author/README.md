# Native binary caller construction

This frozen source authors a single HIA owner for the exact business preconditions, installed config query sequence and JSON request construction of the five original binary handlers. Qualified typed owners and the installed op9 root owner are explicit dependencies. The unchanged original binary.rs source is retained as authority. Native code generation, original function comparison, actual caller integration, remote bodies and public SDK lifecycle remain subsequent gates.

The author only uses the pinned Hepta source authoring utilities. It does not compile or execute Rust, load a native HIA image, call a native tool, or read expected result fixtures. All u64 constants and HIA compositions are assembled and rendered with Python integers; raw resulting files are stored without JavaScript JSON conversion.
