# Linux file metadata native build

The production policy is native/file_metadata.hepta, authored from the exact original target/file_metadata.py and the explicit authoring/file_metadata.pseudo. Both metadata capture/summary and ordered metadata preservation are included. The full CPython xattr implementation and Linux syscall table are retained as source references; the actual interpreter and platform of the later original comparison must be captured separately.

Only copied, reverified actual B3 HIA compilation is allowed. BOOTSTRAP_INPUT.json pins the entire successful Scope graph build ZIP and all archive contents. scripts/bootstrap_input.py verifies every member before copying its real bootstrap and verifies the complete bytes again in the independent build reader. No fallback seed path is admitted. All HIA work is CI-only, under unchanged60/180/900-second and15-minute limits.

The build reproduces both HIA source and composition from their author, proves the full forward/inverse assembly derivations, compiles four HIA owners, runs the actual linker and image packer, and retains complete output/workspace bytes. Four physical corrupted-file controls and two complete relocations use source-owned readers under the full11-probe guard. These are build controls, not application behavior qualifications.

The complete exported archive retains the original successful author process, full source closure, retained B3 input ZIP/extracted files, all compile/link/pack receipts and bytes, bounded process records, failed prefixes, full read-only evidence and control before/after bytes. The main shared123 graph and SSH/Remote routes are untouched.
