This freezes the original file_metadata.py, the actual compiled HIA/native callable, 70 observed inputs, 12 observer-off inputs, and all capture/reader/control sources before the first metadata application execution. The unchanged native build and complete uploaded build read already passed; application status is determined only by this gate's real retained outcomes.

Both fixture processes hold read-only source/target FDs. The HIA native owner never opens, duplicates, or closes those FDs. The journal retains every complete body input/output/workspace, growth prefix, codec child arena, request, actual Linux return and resume. FD4/5 can delay a real syscall; a fixed separately owned actor performs declared fixture changes and may only acknowledge with eight zero bytes.

The input groups include actual ACL and capability attributes, supplementary-group fchown, special mode/hardlink/closed descriptors, nonregular target checks, 256/257 attributes, 64 KiB values, 4 MiB exact/excess, invalid UTF-8 names, full Unicode ordering, U64 link count, content/xattr/rights races, and complete preserve order. Per-object mtime/ctime equality/change relations and metadata-owned fields are compared.

Eight physical corruptions include two honestly resealed case-result alterations. Each is rejected by a guarded complete reader. Two complete relocated copies must give the same full comparison report. All eleven guard prohibitions run for every guard, with before/after complete byte/mode snapshots. Both successful and failed process prefixes are retained. No already captured original or native semantics may be replayed for a reader/export repair.

The semantic archive contains all source, complete actual application buffers/streams, actual production ELF, build-admission process evidence, controls and readers. The complete upstream build ZIP is separately pinned by BUILD_REUSE.json and already independently qualified; it is fully downloaded/restored/read for admission but is not redundantly embedded in every semantic artifact. No HIA compiler or Rust invocation occurs in this qualification.

This scope is Linux and private descriptor APIs. Structured error fields are qualified; the public errno/FD diagnostic adapter and file_info composition are later work. Darwin, SSH, host dispatch, full runtime replacement and old implementation removal are not asserted. The original 60-second exchange, 180-second process, 900-second compiler and 15-minute CI limits remain unchanged.
