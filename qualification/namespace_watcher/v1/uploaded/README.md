# Watcher complete uploaded evidence admission

This source freezes an independent pure read of the complete fixed-eight Watcher capture and the uploaded V5 physical evidence. No compiler, HIA runtime, original Rust binary or completed application is executed.

The frozen reader re-evaluates all 58 cases and 984 operations, reads every full native buffer and every original syscall/process record, and reconstructs all 16 physically rehashed refusals plus both whole-group admissions from their retained files. The final join also checks all original read-only snapshots, process receipts, source bytes and uploaded ZIP members against the independently reconstructed results.

Each pure process retains the existing 180-second limit. The workflow retains complete input ZIPs, frozen sources, process streams, readback reports and actual failures. Prior failures stay attributed to their original executions. Qualification applies only to the private Watcher and its File ownership boundary; namespace-version store/cache/begin/finish and public handlers remain separate work.
