# Descriptor-bound binary read and fingerprint body

Private Linux x86_64 HIA policy. Source authoring alone does not establish execution, public integration or platform-wide parity.

Entry f0(readbuf, mutbuf, mutbuf) -> u32 returns a 64-byte HBRDS001 header on ordinary effects/results. Input HBRDQ001 is 96 bytes: command at 8 (1 start, 2 resume), sequence 16, mode/raw result 24, root length 32, original path length 40, expected-version length 48, expected-version presence 56, offset 64, limit 72, reserved zero 80, payload extent 88. Start modes are 1 read, 2 fingerprint, 3 private_read; payload is the three complete UTF-8 strings. Modes 2/3 require no expected version, offset or limit. Resume requires zeros 32..80 and a complete raw result payload. A reply is copied into private workspace; a repeated resume after output growth must match every reply byte.

Output kind at 8: 0 JSON result, 1 OS request, 2 HIA child request, 3 structured exception, 4 workspace growth, 5 output growth. Sequence is 16, operation 24, arguments 32/40/48, payload extent 56. A successful return of 64 always requires the caller to retain the full 64 + payload extent. Growth puts exact needed capacity at 32. Invalid envelope returns 0xffffffff; output smaller than 64 returns 0xfffffffe. Growth and all ordinary output preserve the unused output tail. The ordinary transport representation must fit below 0xffff0000 bytes; this is a private ABI representability bound, not a new public path policy.

OS operations match the existing text callable mechanical ABI: 1 open / with O_RDONLY|O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC; 2 openat directory with those flags and complete NUL-terminated component; 3 openat regular candidate with O_RDONLY|O_NOFOLLOW|O_NONBLOCK|O_CLOEXEC; 5 close; 6 fstat returning the full Linux x86_64 144-byte stat; 9 geteuid; 11 read with fd at 32 and exact maximum count at 40; 19 lseek with fd at 32, unsigned offset at 40, SEEK_SET. Calls return signed negative Linux errno as u64 bits; read/stat payloads must be complete. HIA owns regular/private checks, exact path normalization and root policy, retry/order, read-until-EOF, version comparisons, resource cleanup and output construction. No adapter chooses a path, reads a whole file, hashes, encodes Base64, or compares versions.

Child operation 1 dispatches the entire payload to binary_codec.hepta. Child operation 2 dispatches it to stat_version.hepta. Child responses return their exact result and initialized bytes. No host codec or version implementation is used.

Exception kind 3 has class at 24: ValueError=1, PermissionError=2, OSError=3, FileNotFoundError=4, NotADirectoryError=5, IsADirectoryError=6, FileExistsError=7, InterruptedError=8, BlockingIOError=9, BrokenPipeError=10, TimeoutError=11, ConnectionResetError=12, ConnectionAbortedError=13, ConnectionRefusedError=14. Errno is 32 (zero means absent), literal message extent is 40, filename-present flag is 48, and payload is the literal followed by the raw UTF-8 filename. Business failures carry exact original literals. OS failures carry errno/filename, leaving platform diagnostic text formatting to a separate HIA caller. This structured error boundary must not be mistaken for a qualified public stderr formatter.

PurePosixPath normalization retains exactly two initial slashes as a distinct lexical anchor, collapses other repeated separators and dot components, rejects any parent component before outside-root checks, rejects the root itself and .hepta- basenames before opening /. Embedded NUL is rejected at the original component-open point. Paths are walked from / using held directory descriptors. Read mode performs both original regular and initial fstats, compares expected version before cursor checks, seeks, obtains the bounded bytes, compares final version, closes the file, Base64-encodes then hashes, and closes the parent. Fingerprint reads through actual EOF, including files longer than their first stat size, with stateful SHA256 and final version comparison. Private read enforces the original uid/link/mode check and 4096-byte bound. All owned descriptors are closed before the terminal result; failed-syscall cleanup in a persistent native caller is explicit.
