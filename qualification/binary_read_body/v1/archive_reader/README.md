# Independent read of the complete binary-read callable capture

This package fetches the exact 72,052,977-byte ZIP uploaded by successful
run 44062962274. It checks the complete ZIP and TAR identities, every unique
ordinary object, and every one of the 44,629 logical files and 1,237 directories.

The full 114 original/native filesystem comparisons, 15 observer-off cases,
30 private controls, six physical corruptions and two complete relocations
are read again from restored immutable bytes. No HIA image, Rust program,
original binary-file operation or filesystem fixture is executed or recreated.
Existing captured process streams and read-only proofs are retained and checked.

Fetch has 60 seconds; restore and pure admission each have 180 seconds.
No implementation replay or budget increase is part of this independent gate.
The proof archive contains this frozen reader, complete new read-only snapshots,
all process streams and the exact original archive binding.
