# HIA held parent-directory owner

The module extracts only the transitive path walk, validation, error and cleanup dependency graph from the already qualified binary read body. Existing selected functions retain exact IR after reversible function-name and call-target relocation. File reading, fingerprinting, encoding and their unreachable helpers are omitted.

HPRDQ001 has the existing 96-byte request layout. Command1 acquires a parent: sequence0, mode1, root length32, full path length40, zero48/56/64/72/80, complete payload length88 and UTF-8 root+path. The held Linux directory is opened by the unchanged root/openat O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC walk. PurePosixPath normalization, root/ancestor checks, anchor behavior and .hepta- target refusal remain the qualified implementation. A NUL in the final name remains data at this parent boundary, exactly as original parent(); the later regular/open stage must reject it. Directory-component NUL is rejected during the actual walk.

Kind6 HBRDS001 grants one trusted graph borrow: sequence16, actual parent FD24, basename byte length32, zeros40/48, payload length56 and complete basename bytes64. The same actual directory descriptor remains owned by this parent context while synchronous children borrow it. No duplicate or path reopening is permitted as a substitute. The loan flag at workspace432 rejects further resume/start. The native capability bridge must verify that the returned FD is its actual owned directory token before granting this internal borrow.

After all children have finished using the descriptor, trusted command3 uses a header-only request, sequence equal to the acquired loan sequence, all other fields zero. It starts the unchanged close/error cleanup machine and clears the loan flag. Native effect completions use command2 with the ordinary exact-sequence/raw-result/payload replay guard and the HPRDQ001 magic. Close is performed once; an error remains an actual structured error. A terminal kind0/3 response has no owned directory left and must be explicitly released before context destruction. Closing an active child borrow is a caller contract violation; the fixed graph must keep the parent context alive throughout all child operations.

This source-author package has no native execution and no public-route claim. Source output must be frozen, built, and compared to actual parent()/close behavior, including rename/symlink races, exact FD lifetime, capacity/replay refusal and observer-disabled execution before use.
