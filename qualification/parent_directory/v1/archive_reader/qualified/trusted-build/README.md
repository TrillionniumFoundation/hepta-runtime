# Held parent native build

Compile the exact 39-function, 2,125-instruction parent-directory HIA owner, the pinned HIA ELF linker and HIA image packer. Assemble only the fixed native custodian and private carrier; invoke the actual HIA linker and packer; independently check all compiler/build/native bytes under the read-only guard. The resulting runtime contains one HIA owner, no Python/libc or child image fallback. This gate executes zero parent/path applications.
