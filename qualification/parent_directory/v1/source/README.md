# Held parent directory qualification

The immutable native callable owns one actual directory descriptor from the exact target parent(root,path) traversal until explicit close or owning process EOF. This private package compares 48 original/native cases and 10 observer-disabled cases, including six actual filesystem mutations, two real RLIMIT_NOFILE bounds, simultaneous independent directory contexts, and two held directories at process EOF.

The complete source, domain, mechanical carrier, exact unedited target function, readers and physical reader controls are frozen before any application executes. The native implementation does not consult Python, expected results, injected syscall returns, or an enabled observer. All application producers and exchanges have 60 second limits, all pure readers have 180 second limits, and the workflow has a 15 minute limit. UNKNOWN applications are not replayed.

The reference executes the target function unchanged with an OS-call observation proxy and reserves fixture FD3 so both processes have the same six transport descriptors before a real descriptor exhaustion test. Fixed native observations use actual fstat of the granted descriptor and then the retired descriptor, complete context/work/input/output bytes, every complete HIA call arena, actual process FDs and mapping guards. Directory mutation actors run in a separate process, never return replacement OS outcomes.

The already built executable is restored from a fully pinned uploaded archive and every source/build byte is reread before use; no application build is replayed. Build-only evidence does not constitute semantic qualification. This package does not qualify file_info, publication, write/upload, SSH, public tools, Darwin, or removal of the old runtime.
