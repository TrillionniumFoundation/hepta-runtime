# Pure HIA binary diagnostic formatter

The sole entry consumes a complete HBRDS001 structured error frame (kind 3).
Class identifiers 1..14 preserve the binary read ABI. Errno 1..4095 requires
the frozen read body's exact wire classification, a zero literal-message length, and either
no filename or a complete UTF-8 filename. Errno zero instead carries the full
literal message with no filename. The effect sequence word is retained input
metadata and does not affect formatting.

A successful return is the complete UTF-8 byte length of the Python-style
class-name, colon-space and exception message, without a trailing newline.
Errno messages, canonical exception classes and all Unicode 15.0 printable
ranges are generated once and embedded in the HIA program. Runtime execution
requires no Python, libc strerror, locale lookup or Unicode database file.
The caller supplies the composition's fixed workspace and enough output space;
0xfffffffe means capacity and 0xffffffff means malformed input. Output bytes
are untouched on capacity or invalid input. Valid output-capacity refusals may
initialize the frozen data region of workspace; all unrelated workspace bytes
remain untouched. The UTF-8 validator IR is preserved from the qualified read
body. This source-only gate does not compile or execute HIA or prove semantic
parity. Its generated bytes must be frozen and separately compared to actual
original Python formatting before any public gateway can use the owner.

For ESRCH (3) and ECHILD (10), the existing read envelope uses its generic
OSError wire class. The diagnostic formatter derives the full Python class
from the errno, rendering ProcessLookupError and ChildProcessError respectively.
Its internal class pool has 16 names; the input ABI remains the original 14
wire classes. This distinction is included in the complete errno domain.
