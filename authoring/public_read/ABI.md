# Default native HIA read routes and catalog

The default stdio executable registers file_info, binary_read and
read_multiple_files through its public MCP frontend. Typed parameters,
configuration, root selection, request construction, result formatting, byte
budgets and remote filesystem behavior are HIA owners. The fixed native
boundary carries buffers, owned processes and kernel I/O.

## Source graph and coverage

the read helpers and direct SSH transport. The five-image catalog retains the
original catalog image and adds four further instances. The total is 162.

## Remote behavior

The original SSH arguments retain -T, BatchMode=yes, ConnectTimeout=8,
StrictHostKeyChecking=yes and ForwardAgent=no. HIA configuration operation 10
supplies the configured target. The 30-second deadline begins before encoding;
there is no automatic retry. Bootstrap transfers exact HIA ELF bytes through
SSH stdin and passes the complete request through an explicitly preserved
descriptor. The helpers use HFRDQ001, HBRDQ001 and HMRDQ001 frames. Multiple-read
keeps both limit-presence bits and the ordered root/path records.

file_info and binary_read retain the original public remote-error chain,
including exception type prefixes. Multiple-read keeps fixed redaction and
never publishes a partial batch. Its final budget uses the original entire MCP
text-result constructor before public projection.

The five original SSH policy owners and fixed transport remain unchanged.
Observable deadline reasons 403 and 703 use the same original public deadline
message. Actual original Rust transport captures exercise both orderings under
the unchanged 30-second deadline. Only reason_literal changed in the public
result owner; its other 29 functions are identical.
DEADLINE_ERROR_CONTEXT.json retains both observations, complete inverse proof
and the earlier failing result.

The derived binary-read body changes only the current Python 3.14 NUL-path
literal; its inverse returns the complete original source, which remains
present. The other two helpers reuse independently qualified immutable source
commits.

Ordinary cancellation notification retains the handler and discards its
response, as in the original SDK. EOF applies the original five-second drain,
then drops pending futures and reaps the owned SSH process. Helpers retain
their qualified parent-death behavior. The runtime waits for no unrelated PID.

## Reproduction

Build in a fresh output directory:

    python3 -I -B scripts/hia_native_runtime_mcp_build.py --source CHECKOUT --hepta HEPTA --bootstrap VERIFIED_B3 --output FRESH_BUILD

Run the portable gate against that production manifest:

    python3 -I -B tests/hia_native/public_read_default/run.py --manifest FRESH_BUILD/build/public-task-batch-extract/manifest.json --output FRESH_EVIDENCE

The runner admits the entire source binding, production ELF, embedded catalog
manifest and complete six-file control package before and after execution.
Private carrier/trace builds are refused. Python is isolated with assertions
enabled and a controlled environment. Fresh evidence retains whole requests,
responses, SSH argv, process observations, original buffers, stdout, stderr
and terminal result identities.
