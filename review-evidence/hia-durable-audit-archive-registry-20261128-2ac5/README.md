It owns reference counts, monotonically distinct identities, expired weak pruning, open reservations, failure rollback and poison/fatal classification. The native storage capability uses an actual process-private futex mutex and grows zeroed storage without an application key-count cap. It retains both mappings if old-storage release fails and preserves sticky error custody.
