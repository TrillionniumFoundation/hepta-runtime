# Native retained audit archive anchor

This component implements the original PinnedLegacyAnchor contract in HIA. It opens the original fixed legacy name relative to the held audit directory, retains the admitted file descriptor and complete bytes, and checks the held and named identity before and after positional reads. It preserves the original 2048-byte bound, private mode/uid/link policy, error order, and descriptor cursor. The borrowed audit directory is never closed by this component.

The HIA actor invokes the independently qualified typed LegacyAnchor HIA parser. Its HIA packer emits the fixed mechanical syscall code. The production boundary has no Python filesystem callback and never exports its private raw descriptor. Pending child calls bind the complete original request and action, and block replay or destruction; acknowledged cancellation closes only the owned anchor once.
