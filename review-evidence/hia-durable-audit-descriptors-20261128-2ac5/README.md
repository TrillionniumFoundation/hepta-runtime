# Native audit directory and hot Record qualification

Three actual HIA actors now cover fixed-original Record I/O and staging cleanup,
configured root/hot directory admission, and complete hot collection. The suite
contains 195 original-versus-native real filesystem cases (63 + 92 + 40) and
30 additional actual HIA boundaries. All outcomes and full post-operation
directory snapshots are compared. Explicit error injection is labeled and is
not represented as a kernel-generated error.

Hot collection retains complete member capture before all staging cleanup,
then all Record reads, original 512/544 limits, full u128/ID ordering, and a
fresh scan description. Root admission retains original ancestor search,
current-euid/mode checks and read-only absence semantics. No unsafe directory
is repaired into acceptance, no refusal becomes absence, and close/UNKNOWN
outcomes are not replayed.

The complete recorded originals archive binds 1,649 original files, including
all raw streams, case descriptions, complete byte-bearing filesystem snapshots,
actual native images, executed fixed Rust oracle ELFs, source composition,
locked dependency receipts, and failed attempts. The 390 expanded fixture
trees are represented by their complete immutable snapshots, including raw
regular-file bytes and symlink targets; their live expanded copies remain
untouched on Desktop. Initial and terminal identities of every archived file
are checked, and Mac independently reads every archive member and mode.

The separate Mac archive preserves all matching author/transport attempts and
drivers, including original failures. qualification.json binds source and
both archives. The earlier f423 Record/Page/FIFO qualification remains its
own ancestor and is not replaced.

These are private actors. Python brokers provide qualification-only actual
system-call effects. The final native descriptor engine, global-context
integration, public ten-handler routing, v12 archive/redb index, cancellation
and restart remain separate open work. No component result claims those gates.
