# Native audit History and descriptor engine

This checkpoint adds a closed syscall engine and its HIA code emitter, the
original weak/strong activity registry policy, and the HIA History composition.
It preserves the full original Cargo dependency/features/profile domain and
uses actual retained directory descriptors throughout Root, Hot and Record I/O.

The engine passed all 195 unchanged filesystem comparisons and 31 additional
private boundaries. The HIA emitter actually generated every code byte used by
History. The three-image compilation/ABI gate contains 68 controls across the
emitter, activity state and initial History refusal paths; it is not 68 emitter
controls. Activity and FIFO synchronization in this QA use real kernel-backed
Python locks and condition variables; final native runtime integration is open.

History first ran 70 actual filesystem scenarios against the complete original
Rust build. Sixty-three matched, and seven exposed a real fatal classification
difference. The original release build aborts at numeric JSON conversion for
selected u128 timestamps above u64. The updated HIA result explicitly preserves
that fatal outcome. The exact same full 70 scenarios passed, followed by 22
held-inode, shared-FIFO, cancellation, malformed-ACK and late-input controls.

The Desktop CAS preserves 3963 recorded original files, all raw streams and
failed attempts, complete byte-bearing filesystem snapshots, actual native
images and original Rust ELF. Expanded duplicate fixture trees represented by
their complete recorded snapshots are listed explicitly. Every archived source
and artifact was checked initially and terminally and independently read back
on Mac. The separate Mac CAS preserves all author, transport and provenance
attempts. The 80,673,922-byte original source package is stored unchanged as its
own complete object; the full 360-crate graph is pinned by its original lock,
locked-archive hashes, actual 11389 compiled source-file checks and all compiler
artifacts. No reference dependency was replaced.

This is a private-component checkpoint. Public ten-handler routing, the native
shared-state synchronization implementation, the public fatal termination
boundary, v12 archive/redb, cancellation/restart and whole-runtime replacement
remain distinct work. No PASS in this checkpoint is assigned to those gates.
